# 第04课实际观察

本笔记由实做操作者根据浏览器实测填写，业务代码由 CodeBuddy Craft 生成。

1. 0 是有效数值：d05 功率实际显示 0 kW；缺失表示没有有效读数，d03 温度显示缺失且无采样时间，不能补成 0。
2. 采样时间来自原始样本，本轮为 2026/10/20 08:00:00；刷新页面只是重新读取，不能把刷新时刻写成采样时刻，也不能凭当前时刻重算样本质量。
3. 当前只有功率 kW 或电压 V 的固定样本，没有累计电量 kWh、电价或计费时段，因此不能从本页直接算电费。

实测：能源始终只有 d05–d08 四台；功率为 0、1.6、1.8、2 kW，切电压为 220、220.2、220.4、220.6 V，再切回功率仍保留 d05 的 0。
