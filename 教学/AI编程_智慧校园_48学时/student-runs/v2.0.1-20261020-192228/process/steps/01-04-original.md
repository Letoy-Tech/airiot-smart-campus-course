## 第 4 步：把外观和操作分开，让菜单能切换

**现在在哪：**CodeBuddy 对话框。这一步会多出两个文件。`styles.css` 管外观；`app.js` 管点击后发生什么。

```prompt
继续当前项目，只完成第01课第4步。
1. 将 index.html 中的样式原样移到 frontend/styles.css，让 HTML 引用它。拆分后外观应保持不变。
2. 创建 frontend/app.js，由 index.html 以 type="module" 引入。九个菜单点击后切换对应内容区域，并突出当前菜单。可以使用 #dashboard、#devices 等地址片段保存当前位置，刷新后仍能回到该菜单。
3. 概览保留现有三张卡片。其他八个菜单各显示自己的中文标题和“这个页面会在后续课程完成”，不要伪装成已经有业务功能。
4. 点击菜单不打开新的网页，不刷新整个浏览器页面。对显示在页面中的文本使用安全的文字写入方式。
保存三个文件，不安装框架，不启动服务。完成后告诉我在哪里引用 CSS 和 JavaScript。
```

**等到什么：**等 AI 保存完成。左侧应能看见 `index.html`、`styles.css`、`app.js` 三个文件。打开 HTML，找到它引用另外两个文件的地方；不要求现在背下写法。

**自己点看：**刷新浏览器，依次点击“设备”“历史”“概览”。停在“历史”时，再按浏览器刷新。

**应该看到：**每次只显示当前页面；“历史”有自己的标题，刷新后还在“历史”；回到概览，三张卡片仍在。

**如果点击没有变化：**先确认 `app.js` 已保存，再单独发：

```prompt
第01课第4步菜单不能正常切换。我将说明点击哪个菜单、页面实际显示什么。请检查 index.html 对 app.js 的引用、菜单对应名称和点击处理，只修复切换问题。不要重写外观，也不要删除现有菜单。保存后告诉我重复哪三个点击检查。
```

菜单切换正确后，进入第 5 步。
