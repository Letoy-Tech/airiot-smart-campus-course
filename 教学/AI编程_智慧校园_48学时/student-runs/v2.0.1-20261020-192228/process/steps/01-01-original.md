## 第 1 步：让空白文件变成第一张页面

**现在在哪：**CodeBuddy 左边的文件区。展开 `frontend`，点开空的 `index.html`。如果文件不存在，右键 `frontend` 新建文件，名字完整写成 `index.html`。

切到可以修改项目文件的 **Craft** 模式，把下面一整段发到 CodeBuddy：

```prompt
我们从零制作一个大学生练习用的智慧校园管理台。当前打开的是 campus-lab 根目录。先读 materials/约定卡.md，只完成本步。

1. 在现有空文件 frontend/index.html 中写一个完整 HTML 页面，页面语言为中文，浏览器标签名和页面大标题都叫“我的校园值班台”。标题下面显示“第一张页面已经打开”和“教学模拟项目”。先不要加入业务数据。
2. 创建 tools/serve.mjs，使用 Node 22 自带模块，不安装依赖。监听 127.0.0.1:5188，只提供 frontend 目录中的文件；不允许读取隐藏文件、项目根目录、backend 或目录外文件。正确设置 HTML、CSS、JavaScript 的类型。/api/* 转发到 127.0.0.1:8098，保留 /api 路径；后端未启动时返回清楚的服务不可用提示。
3. 保存文件，可以运行会自行退出的语法检查，但不要启动常驻服务。

完成后列出实际保存的文件，并告诉我下一步在终端输入什么。不要继续做其他页面。
```

**等到什么：**等 CodeBuddy 的修改结束，并回复保存了 `frontend/index.html`、`tools/serve.mjs`。在左边分别点开这两个文件，确认它们已有内容。若它只在对话中给出了代码而没有保存，回复“请把本步代码实际写入刚才指定的文件并保存”，先完成保存。

**自己运行：**

1. 在 CodeBuddy 打开一个终端，把它命名为 **A-页面**。
2. 看终端当前目录，末尾应是 `campus-lab`。如果不是，先切到这个文件夹。
3. 输入并回车：

   ```sh
   node tools/serve.mjs
   ```

4. 等终端显示本地地址，在浏览器地址栏输入 `http://127.0.0.1:5188`。

**应该看到：**页面上有“我的校园值班台”“第一张页面已经打开”和“教学模拟项目”。终端 A 还在运行，这是正常现象。

**如果没看到：**先核对浏览器地址和终端所在目录。然后单独把这一段发给 CodeBuddy，在它后面补上终端第一条错误；没有错误就写“终端没有错误，浏览器显示……”。不要粘贴密码。

```prompt
我在第01课第1步。预期打开本地地址后看到“我的校园值班台”，现在没有看到。我会附上实际现象和第一条错误。请只检查本步的 index.html 和 serve.mjs，修复这个问题并保存，不继续添加功能，也不要替我启动服务。若修改了 serve.mjs，明确提醒我只重启终端 A。
```

如果修改了 `serve.mjs`，到终端 A 按一次 `Ctrl+C`，再运行刚才那条命令。如果只修改了 HTML，在浏览器刷新即可。看到标题后，进入第 2 步。
