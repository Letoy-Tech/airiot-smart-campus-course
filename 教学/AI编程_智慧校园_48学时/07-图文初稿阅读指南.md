# AI 编程图文教程阅读指南

**第一次用AI做项目，请先打开[00—12手把手教程](walkthroughs/index.html)。** 它从建文件夹、打开网页AI开始，连续完成构思、需求分析、系统设计、真实文件中的代码修改、调试、测试和交付。前期11份设计文件用页面自带保存工具处理；第04篇起在VS Code中修改指定源码，亲自运行并记录结果。[reading/index.html](reading/index.html)是概念、图示和术语的理论参考，实际跟做顺序以手把手教程为准。

这套材料以智慧校园平台为贯穿项目，带领学过一门编程语言的学生，用国内大模型网页工具逐步完成需求、设计、编码、测试和交付。课程总量为 48 学时；软件工程的判断和核验由学生承担，AI 提供方案、代码建议和解释。

## 当前完整资源

[图文资源页](resources/index.html)提供参考运行截图、固定夹具、离线AI练习及既有操作单。新主线使用[学生长期起点](resources/student-project/README.md)：第04篇只复制一次为桌面 `campus-ai-lab/app`，此后逐章启用指定任务并保留前章修改；前期设计仍放在旁边的 `campus-ai-lab/docs`。教师提供完整框架，学生补局部逻辑并验证，不把预置源码算作本人从零写出的成果。

[独立分章练习](resources/student-chapters/README.md)保留为教师专项练习和救援材料，不作为新主线每章覆盖 `app` 的来源；[既有教案](lesson-plans/index.html)可供教师安排12次课，具体点击与命令使用当前手把手篇章。学生自带Windows/macOS电脑，数据库由教师提供；第04篇不依赖数据库，第05—12篇使用完整 `teacher-db` 模式。

## 理论参考版怎样配合跟做

先按手把手教程完成当前一小步；遇到概念不理解，再回理论参考版查看相应场景、学习目标、“本章任务卡”和模块说明。理论正文也包含后续预告、自查与选做，不要求把每段都变成新增作业，不把两套阅读顺序叠加成额外课时。

遇到配图，先尝试用自己的话说明对象、箭头和边界，再回读图注。图中的关系最终要能在接口、数据或操作中找到对应。第03章先学会沿读取链路找字段，ER、状态、并发图是全书地图；第09、11章才深入实现和核验。

每章的实验和提示词帮助学生把问题拆小。不要一次让模型生成整个平台；先核对上下文和允许修改的文件，再应用局部改动，运行并检查。章末练习与教师单独保留的答案用于检查理解，不能代替自己的实现和验证。

手把手主线将每章本人记录保存在 `app/evidence/chXX.md`：先写预期，再填实际结果，截图和报告用路径引用；[课堂任务单](templates/课堂任务单.md)可作为教师补充记录工具，不必重复抄写。课堂落后时按[48学时实施分工](appendices/48学时实施分工.md)缩减重复配置和装饰工作，保留关键业务验证。学生起点已随包提供；教师仍须在第04篇前核对目标电脑与依赖条件，在第05篇前交接组库。前提未就绪就如实记为环境阻塞，不生成假运行结果。

## 三类示例

**教学推演**用于解释概念，例如同时提交相同版本的两个请求。推演结论是规则的预期，不是本机执行结果。

**界面示意**展示字段、状态、交互和布局关系。它不是现有系统截图；学生可以采用不同配色与结构，只要信息和流程正确。

**可执行实验**对应本包实际文件、命令和任务起点。作者的验证结果保存在报告中；学生先填写自己的预期，再执行并记录实际结果，未执行的栏仍写“未执行”。

## 核心与选做

基础项目采用明确标识的教学模拟数据，无需 AIRIOT 账号或模型 API Key。必修完成设备、空间映射、监测、权限、事件、责任、测试与交付。AIRIOT 的真实只读接入留作进阶；不以接入真实硬件或付费模型决定基础成绩。

## 常见术语

| 术语 | 本课程中的含义 |
| --- | --- |
| 接口合同 | 前后端与数据源共同遵守的字段、类型、请求和错误规则 |
| HTTP 与 API | HTTP 是浏览器和服务交换请求/响应的方式；本课程 API 用方法、路径、参数和返回字段描述一次操作 |
| JSON | 用对象、数组和基本值表示数据的文本格式；null 是空值，不是数字零或字符串“null” |
| DTO | 在边界之间传递的数据结构，不等同数据库表或用户实体 |
| 夹具 | 为某个实验固定的输入、账户、数据或时钟，使同一条件可以重复验证 |
| 脚手架与 TODO | 脚手架提供统一起始工程；TODO 指仍需学生补充的具体部分，须能定位到真实文件 |
| 认证 | 确认当前请求代表谁 |
| 授权 | 决定这个身份能否对当前对象执行某个动作 |
| 状态机 | 当前状态下允许哪些动作，以及动作后的状态 |
| 版本冲突 | 提交所依据的记录已经变化，需要回读和重新判断 |
| 事务 | 一组关联修改一起成功，或在失败时一起撤销 |
| 时间线 | 服务端保存的业务动作历史，可追踪操作者、时间和版本 |
| 测试替身 | 为隔离测试而替代依赖的对象；不能证明真实数据库或平台行为 |
| 交接 | 把已完成、实际证据、未解决项和下一任务交给接手者 |
