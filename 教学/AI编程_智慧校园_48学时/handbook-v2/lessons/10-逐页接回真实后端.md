# 第10课：把空间、读数、历史和责任逐页接回后端

这节课沿用前六课已经做好的页面。先让后台准备页面要用的数据，再逐页替换取数方法。每接好一页，就亲手点一遍。

本课4学时，共180分钟。五步建议用时：35、30、30、40、45分钟。

**重新开课：** 用 CodeBuddy 打开原 `campus-lab`，保留已有 `.env`，不重新生成密码。Docker 路线先打开 Desktop并等引擎运行，在 C、项目根执行 `docker compose up -d`、`docker compose ps` 等两服务 `healthy`；原生路线在 C、项目根执行 `python3 materials/native-runtime.py start`、`python3 materials/native-runtime.py status`，确认本目录进程运行，不重新init。A 若已停止，在项目根执行 `node tools/serve.mjs`；若仍运行就沿用，不重复启动。

有旧后端在运行时，先在原 B 按 Ctrl+C。新 B 按[第07课第2步](07-看着页面做第一个后端.md#第2步准备后端终端确认它用的是-java-17)设置本窗口的 Java 17 与已安装的 Node 22，分别执行 `java -version`、`node --version` 确认。B 从根目录进入 `backend`：macOS 用 `cd backend`，Windows PowerShell 用 `Set-Location backend`；已经在 `backend` 不重复进入。B 先保持停止，第1步改完后再启动。

本课每次修改 Java 后，都在 B、`campus-lab/backend` 使用同一组命令：macOS 先 `sh ./mvnw test`，成功再 `sh ./mvnw spring-boot:run`；Windows PowerShell 先 `.\mvnw.cmd test`，成功再 `.\mvnw.cmd spring-boot:run`。后端运行后才回网页登录。只改前端时保存、刷新、重新登录即可。


**环境分支：** 沿用开课前已选路线，详见[环境准入与备用路线](../engineering/07-环境准入与备用路线.md)。只执行自己这一列，不在同一工程混用两套配置。

**发给 CodeBuddy：**

## 第2步：接通概览和能源，保留每个数值的含义
