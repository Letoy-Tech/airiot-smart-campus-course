# 从空白页面做出智慧校园 · V2.1.2

这是48学时手把手教程。前六课先做完整前端，后六课从页面分析数据需求，逐项生成后端并接回页面，最后在新目录交付。

学生先打开 `index.html` 阅读版，或从[开课前](00-先准备再开始.md)开始。每个小步骤都有要复制的提示词、要等的结果、要亲手进行的操作、可见检查以及失败时的修复提示。

学生工程来自 `resources/from-zero-v2/student-start`，首页是空文件。教师参考成品单独放在 `teacher-reference`，不作为学生第一课的工程。

[教师安排](教师安排.md)说明48学时节奏。验证结果见[教师验证记录](教师验证记录.md)。V1文件保留历史查阅，其章节顺序和底座方案不适用于本版。

V2.1.2在原64步中加入需求、ER/状态/时序模型、Git提交与合并、测试设计与故障定位、分档评分；各课仍为180分钟。[工程学习资料](engineering/README.md)中的文档、图和练习均可离线使用，学生在相应课次亲手补全和解释，不以AI生成文档数量代替学习结果。

[版本变更](版本变更.md)列出V2.1.2新增资料和工具。

[反馈修复对照](反馈修复对照.md)逐条回应对方报告，明确已补内容、部分处理和保留的教学安排。V2.1.2为教学说明补充，参考工程与运行工具沿用V2.1.1；其历史验证不改写为新实测。
