### 模块一：预测关联与证据（1学时）

1. 打开`fixtures/catalog.json`，找到`teaching_space_01`。预测：来源空间存在，但初始campusId/buildingId/floor为空；创建本地位置不会改变源文件。
2. 阅读[完整接口合同](../backend/docs/full-api.json)的locations三种写请求。画出校园→楼栋→空间绑定，指出名称与稳定ID各自用途。
3. 在任务单先写三条预期：合法绑定成功；格式合法但不存在的楼栋ID返回404；VIEWER写同一合法请求返回403。每个用例只改一个变量。

### 模块二：补一块并完成关系链（2学时）

4. 在LocationService中搜索`STUDENT_TODO_C05`，只补该块：先确认来源spaceId，再确认本地buildingId。不存在时使用既有业务异常返回404，禁止创建影子空间/楼栋；通用字段400、授权和SQL由教师代码提供。
5. ADMIN登录位置页面，建立名称含组号的校园，例如“G01教学园区”；保存响应id为C。再创建“G01实验楼”，campusId必须选择C。请求示例是`{"name":"G01教学园区"}`与`{"campusId":"实际返回C","name":"G01实验楼"}`，占位文字必须换为实际ID。
6. 选择`teaching_space_01`，绑定刚创建的楼栋B和楼层“1”。PUT路径为`/api/campus/locations/spaces/teaching_space_01`，body为`{"buildingId":"实际返回B","floor":"1"}`；不要添加expectedVersion、actor或时间。
7. 写成功后GET locations/spaces回读，核对绑定和合并字段。故意将B替换为格式合法的不存在ID，只预期404，随后回读确认原绑定未改变。空名称400另用独立请求验证，不与不存在ID混用。
8. 停止并重新启动自己的完整后端，重新登录后回读相同C/B/空间关系，证明不只保存在浏览器。不要重复POST同名校园来“确认”；重试应优先回读已取得的ID。

### 模块三：核验与接力（1学时）

9. 换VIEWER身份先直接提交一条合法空间写请求，检查403及前后绑定相同；不截图Cookie/CSRF值。再以ADMIN正常对照，避免把旧版本、空字段等混成权限案例。
10. 运行check并保存本组实际结果。交接C/B/spaceId、正常与拒绝请求、重启回读及唯一代码差异。达到一条关系链和两个单变量拒绝就停，删除/导入/批量纳管不在本章。

## 本地直接请求小工具（拒绝实验）

当页面下拉框不允许输入非法ID，或VIEWER隐藏写入口时，在本组页面打开开发者工具Console，逐段输入下列函数。它仅访问当前5178教学页面，使用当前登录身份，CSRF只在函数内部传递，不打印。先阅读再执行，不上传Console/Network中的凭据。

```js
async function courseWrite(path, method, body) {
  if (location.origin !== 'http://127.0.0.1:5178' || !path.startsWith('/api/campus/')) {
    throw new Error('只用于本地教学页面');
  }
  const tokenResponse = await fetch('/api/auth/csrf', { credentials: 'same-origin' });
  const csrf = await tokenResponse.json();
  if (!tokenResponse.ok || csrf.code !== 0) throw new Error('请先核对教学会话');
  const response = await fetch(path, {
    method, credentials: 'same-origin',
    headers: { 'Content-Type': 'application/json', [csrf.data.headerName]: csrf.data.token },
    body: JSON.stringify(body)
  });
  const result = await response.json();
  return { status: response.status, code: result.code, message: result.message, data: result.data };
}
```

例一：VIEWER会话执行`await courseWrite('/api/campus/locations/campuses','POST',{name:'本组权限对照校园'})`，预期403/ACCESS_DENIED；ADMIN正常对照改用不重复的组内名称。例二：ADMIN执行`await courseWrite('/api/campus/locations/spaces/not-a-teaching-space','PUT',{buildingId:'替换为实际已有楼栋ID',floor:null})`，预期404；先换真实buildingId，才能隔离非法空间这个条件。非法楼栋对照则使用真实spaceId与不存在buildingId。证据只记脱敏请求体、响应和独立回读，不保存CSRF/Cookie。
