## 进入本章与共同命令

使用教师发放的 `student-chapters/ch06/` 独立目录，保留上一章作品，不覆盖历史。每章起点只留当前任务块，其他章实现由教师预置；不得把预置代码写成本人从零实现。课前按[启动说明](01-跨平台启动.md)核对Node22.21.1、JDK17、JAVA_HOME与锁文件；第05章起采用教师分组MySQL，按[数据库交接单](02-教师数据库交接单.md)落实本组配置和迁移，密码不进入网页AI或Git。

以下命令在当前章节工程根目录执行，Windows/macOS相同。前端依赖尚未安装时先运行`npm --prefix frontend ci`（PowerShell可用`npm.cmd`）。


未补块前需要的页面/响应观察使用教师投影或脱敏样例，个人实际记录在补块后重做。先阅读模块一并填写预测，按模块二补本章代码块；然后执行`node tools/course.mjs build`。build会运行Java普通测试，C07起点质量测试失败是未完成任务的信号，不能删测试。C11无代码块，可直接build。教师显式执行本组授权迁移后，在两个终端分别启动`node tools/course.mjs backend-db`与`node tools/course.mjs frontend`；浏览器进入`http://127.0.0.1:5178/#devices`。后端first-chain入口只供第04章，不能用它的501或两设备结果验收本章完整业务。不要重复启动占用8091/5178的进程。

每份新副本先按启动说明建立一次[学生Git基线](01-跨平台启动.md#学生副本的-git-基线每个新章节一次)，不重新初始化已有本人仓库。每份新副本均须执行`node tools/course.mjs init`初始化本机账号（与Git初始化不同）；登录使用该副本本机生成的密码，组数据库仍保存角色/启用状态。不要混用上章密码或为修登录删除旧库身份。修改Java后停止本组后端、重新build并启动；修改前端通常由Vite更新，但失败快照实验保持页面不刷新、不靠热更新造故障。未补本章任务时，对应检查失败属于起点；填好后运行：

### 模块一：从输入手算结果（1学时）

1. ADMIN或VIEWER登录`#devices`，确认完整响应4空间16设备；实际数量来自items，不从标题或预期表填入。
2. 找`teaching_env_01`、`teaching_energy_01`和`teaching_facility_04`，先写true/在线、null/未知、false/离线三行预测。
3. 在纸上设计一个主视图。选择表格或卡片即可，必须保留模拟来源、设备ID、通信三态、加载/空/失败提示；不要求复刻教师配色。

### 模块二：一个筛选块与页面核对（2学时）

4. 在course.ts找C06，阅读filterDevices真实参数类型。空筛选表示不过滤；名称关键词去首尾空白后匹配；类别、空间、通信条件与名称使用AND组合。保留输入数组，返回派生数组，不用splice破坏原数据。
5. 先只按`teaching_space_01`筛选，应为该空间4设备；再选environment，应只剩`teaching_env_01`；再输入不会匹配的名称，应为空，页面显示没有匹配设备。清除全部筛选应恢复当前响应16条。
6. 单独选择unknown只应匹配online=null，offline只匹配严格false；不能把null当false，也不能将字符串“false”当合法设备输入。多条件组合按实际函数签名执行，不让AI自行增加后端参数。
7. 打开一个设备详情，确认定位使用id而非列表下标。切换筛选后仍能解释详情来源；直接进入或刷新所需详情状态按当前页面实现核对，不新增未定义后端详情接口。
8. 允许修改自己的UI样式，但不更改模拟标识、单位或错误语义。以键盘访问输入、选择器、清除与详情，390px宽度检查主任务，不把浏览器仿真称作真实手机验收。

### 模块三：反例与人工检查（1学时）

9. 用“名称符合但空间不符”的记录反驳OR筛选。观察筛选后数量与原始列表总数分别来自哪里。
10. 保持成功页面，屏蔽设备读取请求再刷新数据，应明确保留旧快照；清除屏蔽恢复。首次失败与成功空数组分别用教师测试用例核对，不能硬编码空数组制造通过。完成check，交接UI选择、筛选输入和结果ID。

模型看不到你的本机。每次只接受局部差异，自己执行命令并对照预期；网络不可用时采用离线卡，不虚构模型回答。

## 验收与停点

| 验收 | 可见依据 |
| --- | --- |
| AC01/AC03三态 | full实际响应与在线/未知/离线设备逐项对应 |
| 组合与清除 | 空间01→4条，加environment→1条，清除→当前总数 |
| AC11可靠性 | 首次失败、筛选空、成功空和旧快照不同；键盘/窄屏可操作 |
| 学生贡献 | C06局部差异和自主UI理由，而非代码行数 |

常见故障：只看两设备先核对teacher-db模式；清除后数据少查是否破坏原数组；详情错位查key和id，不用下标作为身份。
