# 教师参考后端

这是第 12 课完成后的参考实现。学生从空白工程逐课生成，不从这里复制完整后端开始。

先按工程根目录 README 启动本课程 MySQL 和 Redis，再在本目录运行：

- macOS：`sh ./mvnw spring-boot:run`
- Windows PowerShell：`.\mvnw.cmd spring-boot:run`

Java 使用 17。服务地址是 `http://127.0.0.1:8098`。配置从上一级 `.env` 读取。三位用户首次建库时使用其中 `DEMO_PASSWORD`，重启不会重设密码或覆盖课堂修改。不要通过删除数据库解决口令问题。

`sh ./mvnw test` 只验证事件规则与会话边界，不会启动数据库，不代表 MySQL 或 Redis 已完成验证。本实现没有 H2 替代数据库。

教师还需要在隔离的 MySQL 和 Redis 上检查：

1. 健康接口返回 `UP`；未登录读取设备返回 401。
2. 三个账户可以登录；返回内容不含密码哈希；Redis 会话有效期不超过 1800 秒。
3. 概览有 4 个空间、16 个设备、28 个点。未知值仍是 null，真实读数 0 仍是 0。
4. viewer 写入空间、责任或事件被拒绝。manager 不能处理未分派给自己的事件。
5. admin 登记设备责任后创建事件，事件自动分派给 manager。
6. 事件按开始、记录、管理员模拟来源恢复、单独核验、填写结论关闭。漏任一步不能关闭；旧版本号返回 409；关闭后不能写入。
7. 责任或事件写入失败时，业务数据和审计都不应部分保存。
8. 后端重启后 MySQL 中的责任与事件仍在。Redis 重启后旧会话失效，重新登录仍能看到 MySQL 中的业务记录。

仅用于本地课堂。固定的练习数据不会接入真实校园，不提供设备控制或外部通知。
