# V1.0.2 第六轮阅读版优化验收

2026年10月19日。本轮只改图文教程的阅读体验，以及5份Markdown中的加粗标记。参考工程、分章学生起点、教案和配图均未改动，它们的运行结果沿用[第五轮报告](12-第五轮复查与修订验收.md)。V1.0.1及更早的阅读版、ZIP保留原哈希；生成器已禁止写入V1.0.1单文件名。

## 本轮修正

| 范围 | 发现的问题 | 修正后的行为 |
| --- | --- | --- |
| 桌面目录 | 侧栏目录按载入时宽度决定是否展开，窄窗口载入后再放大仍全部折叠；不显示读到哪一章 | 桌面常驻展开，随窗口宽度切换；当前章节在目录中高亮 |
| 章内定位 | 每章约1.2—1.7万像素高，只能回到章首“本章定位” | 1280px以上右栏列出当前章节的二、三级标题并随滚动高亮；901—1279px列在目录下方，只列二级标题 |
| 跨章跳转 | 全页平滑滚动，点目录会以动画滚过数万像素 | 锚点直接跳转 |
| 窄屏 | “回到目录”把读者送回页首，返回原处需重新滚动 | 右下角“目录”按钮显示当前章，打开抽屉目录（当前章节小节在上）；关闭后回到原位置，点链接直接跳转 |
| 章末 | 只有返回目录，没有顺序翻页 | 前言、12章与图表目录之间加入上一章/下一章 |
| 正文行宽 | 1440px下每行约53个汉字 | 正文栏约820px，每行约43字 |
| 封面 | 副标题“当前汇入12章”是编写进度用语；缺少全书总览 | 改为“48学时·12章·40幅教学图·22份常用资料”；按M1—M5里程碑列出12章与学时 |
| 章首 | 每章重复“图文教程·操作与验收分别记录” | 显示学时、模块分配和所属里程碑，数据取自`course-index.json` |
| 示例 | 94处提示词与代码只能手动选择复制 | 每块加“复制”按钮，只复制原文；脚本不可用时按钮不显示 |
| 教材标记 | 第05—08章练习和课程大纲共17处`**练习一：**`，中文冒号紧贴结束符，阅读页显示原始星号 | 冒号移到加粗之外（`**练习一**：`），文字不变；全页复查无残留Markdown符号，仅两处有意保留的`*_test`库名通配 |
| 检查工具 | 新版式下，`verify-reader.mjs`截取高于视口的配图时，Chromium的captureBeyondViewport会在鼠标移动过的长页上卡死渲染进程 | 截图前临时加高视口（宽度不变，版式相同），截完恢复；普通窗口缩放已实测不受影响 |

交互集中在`tools/reader.js`，样式在`tools/reader.css`，生成时内联。脚本失效时，目录、锚点和正文仍可直接阅读。
