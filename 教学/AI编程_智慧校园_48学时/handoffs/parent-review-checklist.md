# 图文初稿主会话验收清单

本清单用于当前初稿交付审阅，不能替代课程软件实验或试讲。

## 内容

- 12 章均有连续解释、具体场景、至少一个有输入和推演的例子，不能只列教学活动。
- 每章三个模块仍为 1＋2＋1 学时；正文、练习及答案要点能对应目标。
- 提示词中附准确上下文与验收，网页 AI 不假称读取或执行本机文件。
- 命令、代码片段、教师提供资源和实际可运行工程分清；未知环境条件保留待核验标识。
- 三角色至少四个身份；管理人员 A/B 的对象范围可区分。
- 事件处置与来源状态分开；恢复、核实与关闭各有独立语义。
- 版本校验仅用于合同约定的事件更新和责任登记，重复恢复的无变更例外准确。
- 责任变更不偷偷改派旧事件；并发和回滚不能用 mock 结果代替真实数据库证据。
- 数据来源、模拟标识、采样时间与 observedAt、有效零与未知、单位都准确。

## 图文

- 每章至少三幅解释性图，全部有可编辑源、成品图、图题、正文引用与替代文字。
- UI 示意不是运行截图；教学假设数据标明是示例。
- 权限和状态图不漏否定路径；箭头不能暗示“恢复后自动关闭”。
- 图不以密集小字替代正文；中文字符、箭头、连线、容器与裁切实际查看正常。
- Markdown 图片文件可本地解析，整书 HTML 可离线阅读核心正文和图片。
