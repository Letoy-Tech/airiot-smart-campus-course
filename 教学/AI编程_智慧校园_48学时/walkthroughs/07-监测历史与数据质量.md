## 第2步：补C07，让判断按正确顺序进行

先读文件上方三个教师函数：`time(n)`检查时间是不是合法整数范围；`value(n)`检查是不是有限数字；`missing(n)`检查是否缺少或为null。参数类型 `JsonNode` 是教师已提供的“装着一项JSON输入的对象”，所以它能表示数字、文字或null；本章不要求自己编写JSON解析器。名字相同的 `value(value)`，左边是检查函数，括号内是输入；不要因为看起来重复就改掉它。

在同一AI会话发送：

```text
现在只给QualityPolicy.classify的STUDENT_TODO_C07_BEGIN与END之间代码。
沿用教师missing(JsonNode)、value(JsonNode)、time(JsonNode)，不改它们。
顺序必须是：非空但类型/时间非法→invalid；任一缺失→missing；
age=observedAt-time.longValue()，age<-5000→invalid；age>60000→stale；
其余fresh。保留签名，不增加依赖，不把字符串转数字，不用系统当前时间。
请给完整可替换的小块，解释为何非法文字+缺失时间仍是invalid。
```

经真实参考源码核对的完整块如下：

```java
if ((!missing(value) && !value(value)) || (!missing(time) && !time(time))) return "invalid";
if (missing(value) || missing(time)) return "missing";
long age = observedAt - time.longValue();
if (age < -5_000) return "invalid";
return age > 60_000 ? "stale" : "fresh";
```

在VS Code只替换两条C07标记之间的 `return "missing"; ...`，不选中标记与函数大括号。按 `Ctrl+S` / `Command+S` 保存。`5_000`与`5000`是同一个整数，下划线只为便于阅读。

回头检查第一行先检查非法类型；如果先判断缺失，`value="bad"、time=null`就会被写成missing，掩盖非法值。两个条件都为空不需要调用 `longValue()`，所以缺失判断必须在计算age之前。

出错时先发送下段，再贴当前整个 `classify` 函数及实际编译错误：

```text
请只定位我接下来贴的classify错误。不要把所有情况改成fresh或missing，
不删除质量测试。检查空值前是否误调用longValue、辅助函数是否保留、
判断顺序与严格边界是否正确。返回C07标记内完整代码；运行由我执行。
```

在证据文件记一条本人解释：“为什么有效0不能用真假判断过滤掉”。不会解释时，让AI用 `0、null、"0"` 三个输入重新演示，不继续堆更多功能。
