# 第02站新增接口约定

GET /api/campus/devices → HTTP 2xx 且 code=0 → data.items；同批观察时间为data.observedAt。复用教师认证与Cookie请求，不向AI提供账号密码。真实HTTP结果待本站浏览器操作后记录。

# 第04站 Ask 结论（操作者摘录）

GET /campus/locations 回校园、楼栋和已绑定关系；GET /campus/spaces 才是来源空间全量。POST /locations/campuses {name}；POST /locations/buildings {campusId,name}；PUT /locations/spaces/{spaceId} {buildingId,floor}。各次成功写后独立回读 locations 和 spaces，失败保留输入，不用本地拼造成功结果。

# 第05站 Ask 结论（操作者摘录）

GET /campus/overview 提供spaces/devices/points/issues/completeness和observedAt；统计由数组计算，台账用spaceId/category/deviceId的hash参数钻取。点值value=null为缺失，数值0保持为0，质量按服务端返回。

# 第06站 Ask 结论（操作者摘录）

GET /campus/history 的deviceId/tagId需属于真实模拟目录，from<=to且跨度<=21600000ms。samples保留原time/value，observedAt是模拟采样时钟，queriedAt是查询时刻。GET /campus/alarms 保留原始字段并按total/limit/skip分页，不提供上游关闭写操作。
