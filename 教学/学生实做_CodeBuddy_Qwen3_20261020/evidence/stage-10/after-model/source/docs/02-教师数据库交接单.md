# 教师数据库交接单

第04章使用 `first-chain`，不需要数据库。第05—12章使用 `teacher-db`；教师先为每组准备独立 MySQL 数据库，学生不必安装 MySQL。课程开发验收另用本机专属 MySQL 8.4.10，它不代表学校数据库已经连通。

## 课前填写

| 字段 | 教师填写与核验 |
| --- | --- |
| 课程班级与小组编号 | 每组单独命名，例如 `campus_course_class01_g01` |
| MySQL 版本 | 建议沿用已验证的 8.4 系列，具体补丁由教师冻结；其他版本先跑本课程数据库测试 |
| 服务器、端口和网络 | 填写学生可达的地址；确认校园网/VPN要求 |
| 数据库名、账号 | 一组一库一账号；不共享业务平台数据库或管理员账号 |
| TLS 和证书 | 远程数据库使用 `sslMode=VERIFY_IDENTITY`，按学校证书配置 JDK 信任库；不要为解决报错关闭校验 |
| 分组隔离 | 账号只能访问自己的 schema；用另组库名请求应失败 |
| 迁移权限 | 教师迁移账号拥有建表权限；常规学生运行账号仅该库 SELECT/INSERT/UPDATE/DELETE |
| 备份和恢复 | 记录课前备份位置、恢复负责人、课后保留期限；恢复先到新的独立库验证 |
| 访问验证 | macOS 与 Windows 各至少一台：网络、JDK、连接、迁移、启动、登录、读写 |

建议30人两人一组，共15个课程库。无法分配15库时由教师排课调整；不要把一组的并发实验混入另一组的数据。

## 本机私密配置

在当前教学工程下创建 `.private/database.json`。真实密码只放这里，不放源码、截图、Git、浏览器 `VITE_*` 或网页AI对话。示例中的大写占位符必须由教师替换：

```json
{
  "url": "jdbc:mysql://DB_HOST:3306/COURSE_SCHEMA?sslMode=VERIFY_IDENTITY&serverTimezone=UTC",
  "username": "GROUP_USER",
  "password": "TEACHER_PROVIDED_PASSWORD",
  "allowAccountAdministration": false
}
```

配置保存于本机用户目录，限制其他用户读取；macOS/Linux可执行 `chmod 600 .private/database.json`。Windows通过文件属性的安全选项只允许当前学生账户和必要的管理员访问。不要在课堂群里公开共享密码。

## 教师准备顺序

1. 用数据库管理工具在课程专用实例新建该组schema和账号。权限只限该schema；SQL模板见 `resources/teacher-guide/数据库开班模板.sql`，模板不含真实密码。
2. 按第04章启动说明完成依赖安装、本地账号初始化与构建。
3. 核对 `.private/database.json` 的目标确为本组空库或已备份课程库，然后由教师执行 `node tools/course.mjs migrate`。Flyway只应用新迁移，不执行clean；已应用文件不可改写。
4. 将配置切换为日常运行账号，执行 `node tools/course.mjs backend-db`。另一个终端执行 `node tools/course.mjs frontend`。
5. 登录管理员，核对全量目录4空间、16设备、28点。新建教学校园和楼栋、关联空间，再读取结果；换VIEWER验证读取允许、写入403。保存自己的证据。
6. 第11章数据库测试使用**另外的测试库**。把其配置保存为 `.private/test-database.json`，库名须以 `campus_course_` 开头、以 `_test` 结尾，例如 `campus_course_class01_g01_test`；测试配置还须由教师明确添加 `"allowTestReset": true`，表示允许清理该测试库中的课程数据，再按后端测试说明运行。不要向日常教学库或原平台库运行测试清理逻辑。

`backend-db`默认不迁移；`migrate`是明确的独立操作。普通学生不需要使用作者本机的 `tools/local-db.py`，该脚本只用于本教材编写环境的隔离验证，不属于Windows/macOS学生安装要求。

## 故障定位

- 连接超时：先核对地址、校园网/VPN和端口；不要把密码贴给AI。
- 认证拒绝：核对账号、允许来源与本组库权限；不要改为root登录。
- TLS失败：核对域名、证书与JDK信任库，由教师修复；不在远程连接关闭TLS。
- Flyway校验失败：保留报错和已应用历史，比较源文件；不要删除历史表或修改已执行迁移。
- 应用读得出但写不入：检查运行账号仅本组库的写权限，以及该操作的角色；权限403与SQL权限失败分开排查。

## 尚需课堂环境完成的确认

学校地址/证书/账号由教师发放；本包不包含它们。Windows实机、学校网络和实际课堂耗时必须由教师课前试跑记录，不能用作者macOS本机结果代替。

参数依据：[Connector/J TLS与主机身份校验](https://dev.mysql.com/doc/connector-j/en/connector-j-reference-using-ssl.html)、[MySQL 8.4 数据库级授权](https://dev.mysql.com/doc/refman/8.4/en/grant.html)（核对日期2026-10-18）。

角色撤销实验使用教师CLI时，课程库名须以 `campus_course_` 开头，并由教师把私密配置的 `allowAccountAdministration` 设为 `true`。工具只管理4个固定教学身份。普通学生配置保持false；不要公开角色修改接口。
