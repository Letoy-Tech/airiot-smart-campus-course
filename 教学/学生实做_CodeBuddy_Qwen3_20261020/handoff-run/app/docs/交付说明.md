# 交付说明（V1.2.0 校园平台学生实做）

本说明只写已有证据，供第一次接手的人按序执行。未执行的项目一律标注“未验证”，不代表通过。

## 1. 交付物

| 路径 | 内容 | 是否交付 |
| --- | --- | --- |
| `app/` | 前端、后端、`fixtures/`、`tools/`、`docs/`、`evidence/` | 是 |
| `app/.private/` | 本机账号与数据库配置 | 否（不入包、不给 AI） |
| `app/lesson-bundles/` | 教师参考 | 否（打包时整目录排除，未读取未复制） |
| `../tools/teacher-local-db.py` | 作者本机专属 MySQL 辅助 | 否（操作者辅助，不是学生成果） |

套件结构为 `app/` 与 `tools/` 并列；所有命令在 `app/` 内执行。`lesson-bundles` 只在课程内部使用，交付包不含它；因此课程内部的 `progress begin`/`show`/`apply` 在交付包中不可用，交付复现一律走 `node tools/course.mjs`。本次生成只用 `plan`、`begin`、IDE 实际生成、`verify`、手工证据、`accept`，未读取任何教师参考。

## 2. 版本与工具

- 起点：V1.2.0 学生工程，共 215 个文件（起点文件数，不是当前文件数）。
- 工具：CodeBuddy CN 4.12.2，内置 DeepSeek-V4.1-Flash（300K 上下文）。
- 模型说明：经用户授权以 DeepSeek 替代原 Qwen；未调用阿里云模型服务，无明文 Key，无购买或充值。

## 3. 安装

前提（缺一项后续必失败）：

1. Node 22.21.1（脚本要求 22.x 且 ≥22.12）。
2. JDK 17，且当前终端同时具备：
   - `JAVA_HOME` 指向 JDK 根目录；
   - `PATH` 包含 `$JAVA_HOME/bin`。
   每个新终端都要重设；`frontend` 子命令也校验，不只是后端需要。
3. 端口 8091、5178 空闲（脚本只报占用，不结束他人进程）。
4. 数据库：见第 4 节，二选一。

执行：

```bash
cd campus-ai-lab/app
npm --prefix frontend ci

export JAVA_HOME="<JDK17 根目录>"     # 按本机实际路径替换
export PATH="$JAVA_HOME/bin:$PATH"

node tools/course.mjs doctor
node tools/course.mjs init          # 首次生成 .private/accounts.json，密码不打印
node tools/course.mjs check         # fixtures + 后端测试 + 前端类型 + 单测
node tools/course.mjs build         # 生成 backend/target/campus-ai-course-0.1.0.jar
```

已存在 `accounts.json` 时 `init` 保留原文件。**`build` 必须先于 `migrate` 和 `backend-db`**，否则报“缺少后端JAR”。

## 4. 数据库准备（二选一）

### 4A. 本机带外层 `tools/`（作者验收机）

macOS 已装 MySQL 8.4.10，路径 `/opt/homebrew/opt/mysql@8.4/bin`，辅助脚本固定使用专属端口 23491 与 `campus_course_lab`/`campus_course_test`。

```bash
python3 ../tools/teacher-local-db.py init    # 建 23491 实例与 lab/test 库，写 .private 数据库配置
node tools/course.mjs migrate                # 明确的一次性 Flyway，只应用新迁移，不 clean
python3 ../tools/teacher-local-db.py use-runtime   # 切到只读写运行账号
```

本节只准备数据库，不启动后端；启动统一在第 5 节两个终端，避免重复启动占用 8091。先执行过 `course init` 时辅助脚本保留 `.private/accounts.json`，仍可首次建立本机数据库；它拒绝已有数据目录或已有管理配置，不覆盖已有实例。`migrate` 只针对 `.private/database.json` 指定的库。验收后数据库测试另用 `.private/test-database.json`（`campus_course_test`，含 `allowTestReset`）。

### 4B. 只拿到 `app/` 包

- 必须由教师提供 `.private/database.json`（`url`/`username`/`password`），格式见 `docs/02-教师数据库交接单.md`。
- 流程：教师执行一次 `migrate`，再把日常运行账号配置写入 `.private/database.json`；启动按第 5 节，本节不启动服务。
- 本包不含密码、账号或库配置；缺该文件时命令明确失败，**不能声称开箱自动可运行**。

## 5. 启动（两个终端）

终端 A（后端 8091）：

```bash
export JAVA_HOME="<JDK17 根目录>"; export PATH="$JAVA_HOME/bin:$PATH"
node tools/course.mjs backend-db
```

终端 B（前端 5178）：

```bash
export JAVA_HOME="<JDK17 根目录>"; export PATH="$JAVA_HOME/bin:$PATH"
node tools/course.mjs frontend
```

浏览器访问 http://127.0.0.1:5178 ，用教师分配的账号登录。尚未配置数据库的早期阶段，终端 A 改 `node tools/course.mjs backend`（first-chain，不连库）。

## 6. 主流程与验证点

1. 登录：CSRF → 登录 → 重新取 CSRF → 身份与能力位。
2. 查设备/空间：并发读取，共用同一批观察时间。
3. 统计与筛选：空间、类型、在线、质量；`null` 为缺失，`0` 是有效样本。
4. 历史：必带 `deviceId`、`tagId`、`from`、`to`，跨度 ≤ 6 小时。
5. 事件：触发 → 分派 → 开始 → 说明 → 来源恢复 → 核实 → 关闭；每步带 `expectedVersion`，写时间线。
6. 负责人：A 改 B 后旧事件保留 A，新事件按当时快照分派。
7. 接入页：只读 AIRIOT `configured`/`connected`，`control=false`。
8. 失效：401 清会话，403 清目录并提示权限变化。

## 9. 首次接手对照表

| 现象或检查 | 原因 | 处理 |
| --- | --- | --- |
| “先设置JAVA_HOME到JDK17根目录” | 当前终端没设或指向错 | 重设 `JAVA_HOME` 与 `PATH`，再 `doctor` |
| “本资源包冻结 Node 22” | Node 版本不符 | 切到 22.21.1 |
| “127.0.0.1:8091 已占用” | 旧后端仍在 | 自行确认并停止自己的进程，脚本不会杀 |
| “缺少后端JAR” | 未 `build` | 先 `node tools/course.mjs build` |
| “请教师先配置 .private/database.json” | 无数据库配置 | 走 4A 或请教师提供 4B 配置 |
| 前端能开但列表空 | 未登录、403 或后端未起 | 先看后端 8091 与登录状态 |
