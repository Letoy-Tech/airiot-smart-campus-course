## 三套工程的关系

- `system/` 是完整示范系统：Vue 3 / TypeScript 管理端、Java 17 / Spring Boot 后端、权限、校园映射、AIRIOT 适配、本地演练、责任登记、审计及部署工具。
- `resources/from-zero-v2/` 是课程教学起点与教师参考工程。
- `student-runs/` 与 `教学/学生实做_CodeBuddy_Qwen3_20261020/` 保留实际试做过程和对应作品。历史目录名称不代表实际使用的模型，具体以实做报告为准。

完整系统与课程精简工程分别保留，阅读或运行前请先进入对应目录。完整系统的上游连接需要使用者自己的 AIRIOT 环境和授权配置；公开仓库不包含既有服务的凭据。

## 资料管理

当前课程正文、教案、配图源文件、工具与工程源码均以可编辑文件管理。历史教学 ZIP 的有效内容经脱敏后按内容去重存储，可按版本重建。依赖、安装器、构建输出、数据库卷、本机秘密和原始桌面捕获不纳入公开 Git。

根目录保留联盟构想与协议范本；对应生成脚本位于 `scripts/`。正文中的具体合作机构已改为泛用称谓，文书仍为范本，不表示实际签署或承诺。
