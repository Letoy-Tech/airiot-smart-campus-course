# 第 12 章：构建交付变更与答辩

状态：`DESIGNED`；4 学时，模块分配为 1＋2＋1。此处是学生项目交付设计，不代表课程文稿已经转换为教案或配套工程已经验证。

## 进入条件与学习目标

已形成第 11 章分层测试证据；真实数据库并发/回滚缺口仍存在时，不得把项目标为完整验收。教师须提供干净复现环境与交付检查模板，确认演示范围。

完成后，学生能在本地或教师批准的隔离环境构建并复现；能处理一个小需求变更并说明影响；能在答辩中独立解释自己的代码、AI 建议取舍和证据边界。公网发布、域名和真实 AIRIOT 接入均不是课程完成门槛。

## 模块一：定义可复现的交付物（1 学时）

交付是让另一位同学按说明重建相同结果。源码、构建产物、运行状态和业务验收是不同证据，不能用一个压缩包或启动截图代替全部证明。

| 交付内容 | 应包含的信息 |
| --- | --- |
| 源码与版本 | 代码版本、依赖锁文件、数据库迁移和种子版本 |
| 运行说明 | 已验证环境、安装/构建/启动顺序、端口及停止方式 |
| 配置示例 | 不含秘密的字段说明，教学数据源选择与演练开关 |
| 质量证据 | 测试矩阵、实际日志、浏览器检查、已知缺陷 |
| 操作说明 | 三角色、模拟标识、事件闭环和责任变更演示路径 |
| AI 协作记录 | 关键提示、采纳或拒绝理由、人工理解与验证 |

教师冻结脚手架后，学生在自己的 `frontend/` 执行约定的类型检查、单元测试与构建；在 `backend/` 执行 Maven 测试与打包。拟沿用 `npm run type-check`、`npm run test:unit -- --run`、`npm run build`、`./mvnw test`、`./mvnw package`；它们只有在资源制作时确认脚本、wrapper 和权限后才成为可用命令，不能在当前文稿目录执行。Windows 按冻结环境说明使用对应 wrapper。

产出：交付清单初稿及每项对应证据位置。

## 模块二：干净复现与一次维护变更（2 学时）

最小实验分为两轮，均使用独立教学副本：

1. 记录源码版本及未提交改动，检查交付包是否误含令牌、数据库口令、私有账户文件或运行日志。配置示例仅保留占位符。
2. 按锁文件安装、执行检查并构建；保存命令、时间和退出结果。后端打包与前端 dist 生成只证明产物可生成。
3. 另一位同学按 README 在干净目录、独立测试库复现。数据库初始化或迁移只针对该库，不连接现有校园数据库。
4. 运行后回读四空间、十六模拟设备、二十八采集点，检查实际数与期望数；验证登录、有效零/未知值、事件闭环、责任变更和刷新持久化。保留尚未验证项。
5. 接收小变更：“事件列表增加按处置状态筛选，刷新后保留已选状态”。若基线已有此功能，由教师换成同等范围的可选只读筛选，不扩展远端控制。
6. 先写变更单：用户问题、验收条件、受影响页面/接口/测试、兼容性和风险；检查现有合同已有 state 参数，优先复用，避免无理由改数据库。
7. 实施最小修改，运行受影响测试并完成浏览器验证；更新 README、变更记录和版本，再由同伴按新版本复现。

出现问题时保留旧版本及失败证据。代码回退和数据恢复分别考虑；本章的小变更优先不动 schema，不能通过删除数据库掩盖升级问题。若确需迁移，先交教师审查新增迁移和隔离恢复方案。

产出：可复现交付目录、同伴复现记录、小变更前后差异及回归证据。实际失败属于可讨论的工程事实，应进入缺陷清单。

## 模块三：演示、个人答辩与经验复盘（1 学时）

小组按“看运行—办事件—查责任”完成演示。每位学生必须独立承担一段代码讲解或故障定位，随机回答至少一个问题：为什么前端隐藏按钮还不够；为什么旧版本返回 409；为什么责任变更不能改旧事件；回滚证据如何排除假通过；AI 哪条建议被拒绝及原因。

教师可要求现场解释一个字段从页面到数据库的路径，或分析一份新错误日志。评分结合个人说明、过程记录和实际结果，不以界面与原系统相似度、提示词长度或 AI 生成代码量评分。

产出：小组演示记录、个人答辩记录、问题与改进清单。

## 典型问题、巩固与课程接力

“我电脑能跑”：检查未登记的环境变量、种子和依赖漂移。构建成功但页面打不开：区分启动命令、代理地址、资源 base 与路由，不直接改业务代码。验收证据版本落后：重跑受影响检查，历史报告不改写成新结果。答辩只复述 AI：回到实际代码和一次失败日志解释因果。

课后提交个人复盘，说明一个误判、一次修复及下次的验证策略。进阶可在另行批准的隔离环境学习发布和恢复，或完成只读 AIRIOT 适配；不影响基础课程成绩。

课程终点：整理项目包和个人证据索引，列出剩余缺陷与接手步骤。教材作者另行完成配套工程制作、干净环境实验验证和人工审校后，才把课程源稿转为学校教案；学生项目交付与教材 `LESSON_READY` 状态分别记录。
