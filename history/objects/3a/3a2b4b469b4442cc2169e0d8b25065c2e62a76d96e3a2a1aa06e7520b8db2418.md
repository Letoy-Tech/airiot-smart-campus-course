# 第12章 · 交付变更与答辩操作单

4学时，1＋2＋1，建议45＋90＋45分钟。当前任务为`C12`；其余基础由教师预置，两人中途换手，个人解释分别记录。

## 进入本章与共同命令

使用教师发放的 `student-chapters/ch12/` 独立目录，保留上一章作品，不覆盖历史。每章起点只留当前任务块，其他章实现由教师预置；不得把预置代码写成本人从零实现。课前按[启动说明](01-跨平台启动.md)核对Node22.21.1、JDK17、JAVA_HOME与锁文件；第05章起采用教师分组MySQL，按[数据库交接单](02-教师数据库交接单.md)落实本组配置和迁移，密码不进入网页AI或Git。

以下命令在当前章节工程根目录执行，Windows/macOS相同。前端依赖尚未安装时先运行`npm --prefix frontend ci`（PowerShell可用`npm.cmd`）。

```text
node tools/course.mjs doctor
node tools/course.mjs init
```

未补块前需要的页面/响应观察使用教师投影或脱敏样例，个人实际记录在补块后重做。先阅读模块一并填写预测，按模块二补本章代码块；然后执行`node tools/course.mjs build`。build会运行Java普通测试，C07起点质量测试失败是未完成任务的信号，不能删测试。C11无代码块，可直接build。教师显式执行本组授权迁移后，在两个终端分别启动`node tools/course.mjs backend-db`与`node tools/course.mjs frontend`；浏览器进入`http://127.0.0.1:5178/#cases`。后端first-chain入口只供第04章，不能用它的501或两设备结果验收本章完整业务。不要重复启动占用8091/5178的进程。

每份新副本必须init；登录使用该副本本机生成的密码，组数据库仍保存角色/启用状态。不要混用上章密码或为修登录删除旧库身份。修改Java后停止本组后端、重新build并启动；修改前端通常由Vite更新，但失败快照实验保持页面不刷新、不靠热更新造故障。未补本章任务时，对应检查失败属于起点；填好后运行：

```text
node tools/course.mjs check
```

`check`包含的普通测试不自动等于MySQL集成通过；数据库实际检查另按第11章执行。真实结果填写本章任务单，文中“预期”不当作已发生的记录。

### 模块一：冻结可说明的起点（1学时）

1. 在当前章节工程检查Git差异和文件清单，记录基线A：核心业务来自教师及前章成果，本章状态筛选任务未完成。不能把未填C12的测试失败隐去。
2. 补README中的版本、Node/JDK、数据库交接方式、初始化/迁移/启动/停止顺序及测试入口。配置样例只放键和占位，`.private`、Cookie、密码、真实学校数据不打包。
3. 写变更验收：切换合法state后skip=0；刷新保留合法state而回到首屏；未知state不发给后端；后发查询优先；失败保留可解释状态。

### 模块二：完成一个筛选变更并交叉复现（2学时）

4. 在course.ts补C12 changeCaseState，复用已有类型与筛选对象；改变state时只按合同更新state并将skip设0，不重写事件接口，不修改数据库结构。
5. 在有多页事件的教师隔离数据上进入后续页，再切换为不足一页的IN_PROGRESS，检查请求skip=0及结果；不能把旧skip造成的空页误当没有事件。
6. 用hash `#cases?state=NEW`进入，再刷新，保留合法NEW并从skip=0读取。用其他合法状态重复；未知状态按页面既有校验回到合法默认值。实际排序与分页以full-api.json为准，不从数组顺序推断所有历史。
7. 运行check与build，保存受影响测试及浏览器记录，形成基线B。构建产物生成只证明可构建，不等于部署或数据库业务验收。
8. 同伴在独立解压目录或另一已预检机器按README复现：安装依赖、独立账户配置、教师分配的独立schema、迁移、完整启动、角色读取、一个事件/责任关键路径。只复制无秘密源码和锁文件，不复制他人的库或登录文件。基线B重点重验筛选、刷新、分页和竞态。

### 模块三：个人答辩与交付（1学时）

9. 每人回答一条：输入怎么进入代码、为何拒绝一个反例、AI建议哪处被采纳或修订、哪些证据尚未覆盖。伙伴不能代答全部问题。
10. 交付源文件与锁文件、迁移、无秘密配置说明、资源版本、需求/合同决策、分层测试与缺陷、AI代表记录、HANDOFF。不打包node_modules/target/dist的偶然副本作为源码；若另交构建产物须标版本、哈希与用途。
11. Windows物理设备、课堂时间或真实AIRIOT若未测，保留未测；完整课程代码完成与学校开课验收是不同结论。正式公开部署、设备控制、通知仍不在必修范围。

## 验收与停点

| 验收 | 可见依据 |
| --- | --- |
| AC11变更 | 筛选/刷新skip归零、合法state恢复、竞态和失败语义 |
| AC12复现 | 接手者、独立目录/库、实际命令与核心结果，缺口单列 |
| 交付完整 | 锁文件/迁移/无秘密配置/版本/证据/HANDOFF可定位 |
| 个人答辩 | 独立解释一个分支、一个失败与一次AI判断 |

常见故障：作者电脑能跑但新目录失败先查漏锁文件/迁移/配置来源；错误空页查skip；旧代码回退不等于旧数据恢复，不能用覆盖数据库“修复”交付。
