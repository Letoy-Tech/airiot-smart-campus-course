# AI 编程图文初稿阅读指南

这套材料以智慧校园平台为贯穿项目，带领学过一门编程语言的学生，用国内大模型网页工具逐步完成需求、设计、编码、测试和交付。课程总量为 48 学时；软件工程的判断和核验由学生承担，AI 提供方案、代码建议和解释。

## 第三轮新增资源

[图文资源页](resources/index.html)包含实际首次链路截图、可筛选的固定夹具和六张离线AI练习；[第04章操作单](resources/campus-ai-course/docs/04-首次贯通操作单.md)对应两处学生TODO。已确定学生自带Windows/macOS电脑、数据库由教师提供。首次链路暂不依赖数据库，后续业务实验仍待逐章落实。

## 一章怎样读

先看场景、学习目标和“本章任务卡”，确定起始材料、自己要改的部分以及完成证据，再跟随三个模块学习。任务卡是本章课内路径，整章正文也包含后续预告、自查练习和选做内容，不要求把每一段都转成新增作业。

遇到配图，先尝试用自己的话说明对象、箭头和边界，再回读图注。图中的关系最终要能在接口、数据或操作中找到对应。第03章先学会沿读取链路找字段，ER、状态、并发图是全书地图；第09、11章才深入实现和核验。

每章的实验和提示词帮助学生把问题拆小。不要一次让模型生成整个平台；先核对上下文和允许修改的文件，再应用局部改动，运行并检查。章末练习与答案要点用于检查理解，不能代替自己的实现和验证。

建议每章只维护一份[课堂任务单](templates/课堂任务单.md)：先写预期，再填实际结果，证据用路径引用。课堂落后时按[48学时实施分工](appendices/48学时实施分工.md)缩减重复配置和装饰工作，保留关键业务验证。开始第04章前，教师须完成目标机房预检；没有脚手架时先做独立短例，贯通实验如实记为资源阻塞。

## 三类示例

**教学推演**用于解释概念，例如同时提交相同版本的两个请求。推演结论是规则的预期，不是本机执行结果。

**界面示意**展示字段、状态、交互和布局关系。它不是现有系统截图；学生可以采用不同配色与结构，只要信息和流程正确。

**待实测实验**描述拟定教学工程中的操作。教师脚手架和运行条件尚需准备，命令、代码与预期须在该工程上逐项核验后，才能转为正式实验教材。

## 核心与选做

基础项目采用明确标识的教学模拟数据，无需 AIRIOT 账号或模型 API Key。必修完成设备、空间映射、监测、权限、事件、责任、测试与交付。AIRIOT 的真实只读接入留作进阶；不以接入真实硬件或付费模型决定基础成绩。

## 五个里程碑

| 里程碑 | 完成章节 | 应能解释的问题 |
| --- | --- | --- |
| M1 定义项目 | 01—03 | 谁需要什么，数据和接口为何这样设计？ |
| M2 设备可见 | 04—06 | 页面上的设备怎样经过后端读取出来？ |
| M3 数据可信 | 07—08 | 读数什么时候有效，谁有权做什么？ |
| M4 业务闭环 | 09—10 | 事件怎样合规关闭，责任变化留下什么记录？ |
| M5 可交付 | 11—12 | 如何证明失败路径正确，别人怎样复现和接手？ |

## 常见术语

| 术语 | 本课程中的含义 |
| --- | --- |
| 接口合同 | 前后端与数据源共同遵守的字段、类型、请求和错误规则 |
| HTTP 与 API | HTTP 是浏览器和服务交换请求/响应的方式；本课程 API 用方法、路径、参数和返回字段描述一次操作 |
| JSON | 用对象、数组和基本值表示数据的文本格式；null 是空值，不是数字零或字符串“null” |
| DTO | 在边界之间传递的数据结构，不等同数据库表或用户实体 |
| 夹具 | 为某个实验固定的输入、账户、数据或时钟，使同一条件可以重复验证 |
| 脚手架与 TODO | 脚手架提供统一起始工程；TODO 指仍需学生补充的具体部分，须能定位到真实文件 |
| 认证 | 确认当前请求代表谁 |
| 授权 | 决定这个身份能否对当前对象执行某个动作 |
| 状态机 | 当前状态下允许哪些动作，以及动作后的状态 |
| 版本冲突 | 提交所依据的记录已经变化，需要回读和重新判断 |
| 事务 | 一组关联修改一起成功，或在失败时一起撤销 |
| 时间线 | 服务端保存的业务动作历史，可追踪操作者、时间和版本 |
| 测试替身 | 为隔离测试而替代依赖的对象；不能证明真实数据库或平台行为 |
| 交接 | 把已完成、实际证据、未解决项和下一任务交给接手者 |

## 当前阅读边界

本轮目标是可阅读、可继续修订的图文初稿。配图检查证明图片能够正确呈现，内容审校证明规则表述一致；两者都不能替代软件实验、课堂试讲或正式教案。后续继续沿 [编写进度与教案转换](05-编写进度与教案转换.md) 完善资源与实操证据。
