# 图文教程、教案与教学资源维护

当前维护对象是完整教程：12章、40幅图、22份内嵌资料、12次课教案。`reading/index.html`是日常入口，`course-index.json`记录当前版本。旧轮阅读版、验收报告与ZIP为历史证据，不能覆盖或拿来证明本次修改通过。

## 先准备作者工具

以下命令从课程根目录执行，只用于重建教材与检查网页。学生工程另按 `resources/campus-ai-course/docs/01-跨平台启动.md` 操作。

```text
npm --prefix tools ci
npm --prefix tools exec -- playwright install chromium
```

使用Node22。Windows PowerShell遇到npm脚本策略限制时，把命令中的`npm`写成`npm.cmd`，无需修改全局执行策略。首次恢复npm依赖、安装浏览器需要网络；发放的阅读页本身不需要网络。

`tools/package.json`和锁文件声明Mermaid、marked及Playwright。默认使用本目录安装的依赖，不要求接力者拥有作者电脑上的Codex缓存。确需使用已验证的外部运行库，可显式设置`COURSE_NODE_MODULES`；浏览器路径可用`COURSE_CHROMIUM_PATH`指定。不要把这些机器路径或浏览器二进制打进教学包。

## 从Markdown重建阅读版

先修改`manuscript/`、相关操作单或合同，再生成HTML。不要只改生成后的HTML。

```text
node tools/build-reader.mjs --strict --output reading/index.html
node tools/build-reader.mjs --strict --embed-images --output reading/AI编程图文教程_V1.0.1_单文件.html
node tools/build-resources.mjs
```

后续版本应把单文件名中的`V1.0.1`换成新的版本，保留已有归档。生成器禁止使用V0.2/V0.3/V0.4和已交付的V1.0历史文件名。

普通阅读版依赖同包图片，单文件版内嵌40幅PNG及SVG下载数据。22份常用资料内嵌为书内锚点；其他资料仍标注“需完整资料包”，原系统的背景参考标注“需原项目”。单文件HTML不是完整工程或学生代码包。

## 检查网页与链接

每次检查使用本轮新的输出目录，不覆盖旧轮JSON与截图。

```text
node tools/verify-reader.mjs --input reading/index.html --output illustrations/qa/round5-book --skip-pdf
node tools/verify-reader.mjs --input reading/AI编程图文教程_V1.0.1_单文件.html --output illustrations/qa/round5-standalone --skip-pdf
node tools/verify-resources.mjs --output illustrations/qa/round5-resources
```

检查覆盖1440px和390px、离线图片、章节导航、锚点、脚本错误、页面溢出；单文件版另检查PNG下载内容。资源页还检查本地文件链接和第08章到第05章请求工具的实际跨章跳转。自动检查后应打开截图，检查文字、图字和表格可读性；浏览器视口不是手机真机验收。

`--strict`检查12章及每章至少3幅对应教学图，不替代内容审校。源码与构建报告哈希必须对应，修改源码后须重新构建。

## 教案维护

`lesson-plans/lesson-source.json`是12次课的直接编辑源；`tools/prepare-lessons.py`保存最初编排草稿，不应无条件重新运行来覆盖已修订的源稿。每次调整核对48学时、2160教学分钟和各课次180分钟。

`tools/build-lessons.py`从JSON生成Markdown、HTML和Word。它需要python-docx和Pillow；在Codex中使用`load_workspace_dependencies`返回的文档运行时Python。非Codex接力者可使用Python3.12，在Python虚拟环境安装固定依赖，再运行构建器：

```text
python -m venv .venv-author
# Windows
.venv-author\Scripts\python.exe -m pip install -r tools/requirements-author.txt
.venv-author\Scripts\python.exe tools/build-lessons.py
# macOS
.venv-author/bin/python -m pip install -r tools/requirements-author.txt
.venv-author/bin/python tools/build-lessons.py
```

macOS若没有`python`命令，创建虚拟环境时使用`python3`。这是教师维护工具，不要求学生安装；打包时排除`.venv-author`。非Codex机器可用本机Word或LibreOffice导出PDF，再逐页检查；本轮仅验证了作者运行时。

Word须经文档运行时转换为PDF，逐页打开渲染图检查，确认没有中文缺字、表格截断或图字过小，再替换正式PDF。仅生成DOCX不表示PDF已同步。

现有教案为37页：1页总览，加每课目标与准备、活动与评价、完整教学图3页。当前PDF中的中文已采用可用中文字体解决渲染缺字；换机器时重新核对字体，不能只看PDF提取文本。旧`lesson-plans/qa`只证明当时文件，不能套用到新导出。

## 配图源与样式

`figure-sources/`保留Mermaid或SVG逻辑源；`illustrations/`保留PNG/SVG成品。宽图或复杂图的`.figure.json`可能用`renderSource`指定`figure-sources/layouts/`固定SVG；改逻辑时同步逻辑源与版式源。固定布局由`make-fixed-layouts.py`生成，避免只改成品后被脚本覆盖。

保持白底、深蓝正文、浅蓝/浅青分组，配文字与线型说明，不只用颜色传意。每图解释一个教学问题，中文字体采用PingFang SC、Noto Sans CJK SC、Microsoft YaHei或Heiti SC等可用字体。图片写清“教学示意”，实际运行截图另注明模拟来源、环境与范围。

每图的元数据提供图号、标题、说明、替代文字和证据类型。正文独占一段引用PNG，并在相邻段落解释读图顺序。图注、PNG、SVG和图号应对应。`prepare-book-figures.py`属于首次编排辅助工具，不应在当前正文上无参数重跑。

## 分章学生包与打包

学生起点由参考工程的`tools/student-checkpoints.mjs`产生；现有目标拒绝覆盖。不能覆盖学生已有作业。维护教师基础代码时，先记录生成清单，再核对每个受影响副本只含本章任务，重新检查源码哈希、夹具清单、编译和指定失败断言。

教师复验入口为`resources/campus-ai-course/tools/verify-student-checkpoints.mjs`，它不分发到学生副本。真实MySQL用例只对教师明确配置的课程TEST库运行；不得借用业务库。

打包排除`node_modules`、`target`、`dist`、`.private`、`.runtime`和日志，包含锁文件、源码、教案和清单。新版本ZIP使用新文件名；校验解压、CRC、逐文件SHA及敏感配置排除。旧轮工具与报告保留为历史参考，当前验收以本轮报告和文件哈希为准。
