# 第 06 章教师参考：组合筛选与自主界面

仅供教师备课和提交预测后的讲评。建议4学时：45分钟理解、90分钟操作、45分钟核验；30人分15组，实践中交换实现者与审查者。每章只有约定检查点由学生填写，框架、其他章节功能和安全基础已预置。

## 关键答案与讲评顺序

`domain/course.ts` 的 C06 是唯一必改代码块。参考实现的关键词在名称和ID中匹配；空间、类别、通信状态与关键词为 AND。空选择表示全部。筛选返回新数组，不删除原列表。

```ts
const keyword = filter.keyword.trim().toLocaleLowerCase()
return devices.filter(d =>
  (!keyword || `${d.name} ${d.id}`.toLocaleLowerCase().includes(keyword)) &&
  (!filter.spaceId || d.spaceId === filter.spaceId) &&
  (!filter.category || d.category === filter.category) &&
  (filter.online === 'all' ||
   (filter.online === 'online' && d.online === true) ||
   (filter.online === 'offline' && d.online === false) ||
   (filter.online === 'unknown' && d.online === null)))
```

full数据清除筛选后16台；teaching_space_01有4台，再选environment剩1台。不存在关键词为0，显示无匹配并可清除；第一次请求失败显示错误而非0台。`onlineLabel`严格区分true/false/null，不能用Boolean()。详情按稳定deviceId定位，UI布局可自定，不以像素复刻评分。

## 常见故障与课堂替代

0台先区分预期C06起点空实现、无匹配与请求失败；有数据仍错误时查看响应是否重复解包；详情丢失先查稳定ID，不依赖数组下标。

可先使用教师普通表格，学生只改筛选并说明两项信息优先级；窄屏/键盘检查仍做。网络故障用脱敏样本推演，不能记为页面通过。

## 课后题参考答案


**练习一：**接口成功返回十六条，当前筛选只匹配三条。页面应显示哪个数字？

答案要点：可显示“3 / 16 条”，两个数字各有来源；若只写结果数，写三条。最终预期规模不能代替当前响应数量。

**练习二：**设备有 `spaceId`，但对应空间 `buildingId=null`。应该删除详情入口吗？

答案要点：不应。设备仍存在，可以显示来源空间和“尚未绑定楼栋”；位置缺项不意味着设备不可读取。

**练习三：**同学将筛选函数的三个条件改成 `||`，会怎样？

答案要点：只要名称、类别或空间任意一项符合就入选，违背组合筛选。用一台名称符合但空间不符的夹具，即可发现差别。
