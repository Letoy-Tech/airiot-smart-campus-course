# 第 12 章教师参考：有限变更与可复现交付

仅供教师备课和提交预测后的讲评。本章4学时按1＋2＋1组织：第1学时10分钟预测、20分钟补C12、15分钟针对性回归；第2—3学时15分钟构建打包、30分钟复现、45分钟前9组展示；第4学时后6组展示30分钟、个人退出题15分钟；30人分15组，实践中交换实现者与审查者。每章只有约定检查点由学生填写，框架、其他章节功能和安全基础已预置。

## 关键答案与讲评顺序

C12参考：`return { state: validCaseState(state), skip: 0 }`。既有validCaseState只接受四个合法状态，非法恢复为空筛选。该块用于变化和恢复；不能保留上一页skip造成“没有结果”。URL哈希只恢复合法筛选，不恢复上次页码。

基线A是本章起点，明确C12未完成，不冒充全功能版本。补块后做针对性回归，形成B再完整检查、构建和同伴复现；不要求A先通过。分页准备严格照[第12章操作单](../campus-ai-course/docs/12-交付变更与答辩操作单.md#教师课前准备可执行的分页演示数据)：单独空白库先确认total=0及env01无责任人，触发14条NEW，再分派其中2条给实际账号manager-a；得到NEW12、ASSIGNED2、IN_PROGRESS0，每页10条。不是空库就另供独立库，不删既有学生数据。4条/limit=2的JSON只是API规格，不是UI种子；准备和课堂执行必须各留实际记录，本次文稿修订未执行写库。基线B包含实际源码、锁文件、版本说明、无秘密示例、分层证据与已知缺口。

同伴在独立目录与教师批准的隔离库复现，记录真实系统与工具版本。构建成功不能替代HTTP/浏览器/数据库证据；macOS运行不能推出Windows物理机已验收。每人解释自己的一块修改、一次AI取舍、一条拒绝证据；同组共用项目不取消个人答辩。

## 常见故障与课堂替代

端口占用只停止本人进程；依赖失败不随意更新lock；路径含空格用工具或引号；打包排除.private/.env/Cookie/数据库密码/运行日志秘密。

同伴设备故障可换另一授权干净目录，但如未跨操作系统就如实注明；可延期实际设备复现，不伪造签名或截图。

## 课后题参考答案


1. 前端 dist 已生成，能否写“校园系统验收通过”？

答案要点：只能报告对应构建结果；还需运行、带身份 API、浏览器及相关数据库证据。

2. 状态筛选复用既有 state 参数，为什么还需要影响分析？

答案要点：请求参数、刷新持久化、分页、加载竞态、错误显示和文档均可能变化；没有 schema 变化不等于没有风险。

3. 当前代码通过测试，但交付包漏了迁移脚本，会发生什么？

答案要点：新环境无法重建结构；作者已有数据库掩盖了缺口，构建通过不能代替干净复现。

4. 回退到旧代码是否必然恢复旧数据？

答案要点：不会。代码与数据生命周期不同；必须检查兼容性，数据恢复需要独立方案与验证。

5. 同伴只复现了 ADMIN 闭环，如何写结论？

答案要点：明确管理员已测范围，A/B 本人范围与 VIEWER 拒绝仍待执行；不能扩大成四身份验收。
