# 课程编写约定

本文件是本课程 Markdown 源稿的共同约定，供分章编写和 AI 接力读取。更新时间：2026-10-18。

## 已确认条件

- 课程名称：AI 编程——以智慧校园平台重建为例。
- 对象：学过一门编程语言，但没有完整项目经验的学生。
- 课内总量：48 学时，12 章，每章 4 学时。这里的学时是学校教学计量单位，尚未指定每学时分钟数；不要自行换算成自然小时。
- AI 主线：学生自行使用通义等国内网页聊天工具。Qwen3 是模型教学案例，不要求购买 API、安装智能体工具或本地部署模型。记录界面实际显示的型号；无法核实时写“未显示”。
- 项目：以已有智慧校园系统的业务和工程问题为参照，在独立教学工程逐步实现。界面允许重新设计。
- AIRIOT：保留客户端与适配思路作为教师参考资源；教学数据源需另行制作；真实 AIRIOT 只读接入作为课外进阶选做，0 必修学时。
- 当前产物阶段：课程总纲、12 章分模块设计稿、AI 接力资料和资源制作规范。它们是后续教材正文、实验材料及教案的源稿，不等于配套工程已实现或课堂已试讲。

## 教学版共同边界

- 技术栈沿用 Vue 3、TypeScript、Vite、Pinia、ECharts，Java 17、Spring Boot 3.4.2、MyBatis、Flyway、MySQL。教师冻结依赖与锁文件；不在课堂追逐最新版本。
- 教师预备项目骨架、经过验证的认证基础、可重复的数据库环境、模拟数据端口、种子数据、错误注入与测试模板。它们目前是待制作资源，禁止写成“已提供可下载包”。
- 学生编写需求、设计、接口和业务实现，完成授权、状态机、测试及交付。认证底层、通用账户管理、Redis 运行细节不作为从零实现任务；教师脚手架是否保留 Redis 必须在制作阶段固定并实测。
- 独立教学工程示意根为 `campus-ai-course/`，其中 `frontend/`、`backend/`、`docs/`、`fixtures/`、`evidence/` 是拟定目录，当前文档包不包含该工程。
- 保留四空间、十六模拟设备、二十八采集点作为最终演示数据集规模。第一条贯通可先用一空间、两设备；所有记录均为教学模拟数据。
- `CampusDataProvider`、`TeachingMockProvider`、`AiriotProvider` 是待实现的教学设计名称，并非现有系统已有类。
- 教学接口来源使用 `TEACHING_MOCK | AIRIOT`；来源标记和 `simulated` 是不同维度。真实 AIRIOT 里的模拟设备仍为 `simulated=true`。
- 模拟数据由教师提供确定性种子和可控时钟。启动时显式选择来源，真实上游失败不能静默变为模拟成功。
- API 外层沿用 `{code:0,message,data}`。监测、空间与设备等读接口尽量对齐现有 `/campus/...` 合同。
- 三角色：ADMIN、CAMPUS_MANAGER、CAMPUS_VIEWER。管理员管理，管理人员只处理分派给本人的事件，查看者只读；后端负责最终授权。
- 事件来源 `DEMO/LOCAL_DEMO`，状态 `NEW → ASSIGNED → IN_PROGRESS → CLOSED`。管理员模拟恢复，处理者独立请求核实，满足处置记录、已恢复、核实通过、结论后才能关闭。
- 修改使用 `expectedVersion`，旧版本返回 409。前端保留输入、回读新记录，不自动重放。事件主记录与时间线在同一事务提交；真实数据库回滚和并发是必需的集成证据。
- 设备责任变更仅影响随后创建事件的自动分派，不偷偷改派已有事件。审计中的操作者和时间由后端产生。
- 真实远端控制、外部通知、真实学生个人信息不纳入基础作业。AIRIOT 原始报警只读，与本地演练事件分开。
- 未知值不能补零；有效零不能被隐藏；V、kW、kWh 不可混用；不添加没有数据依据的费用或节能率。

## 分章文件统一要求

每章有三个模块，学时分配为 1、2、1，总计 4。各模块写清概念、具体操作和产出，不列空标题。每章须有：进入条件；可观察学习目标；三个模块；最小实验步骤；可复制的网页 AI 任务提示；人工检查点；验收表；常见错误及定位；课后巩固；进阶选做；下一章接力。章节中的测试结果一律为待执行预期，不能声称已经通过。

现有系统代码只作为教师参考；不能把参考工程的历史报告、账户或运行配置当作学生作业。章节之间共享合同，不各自发明字段和状态。所有具体脚手架路径和命令应写明执行条件，不能让读者以为当前目录中已有可运行工程。

## AI 接力与完成定义

区分 `DESIGNED`（模块设计稿）、`WRITTEN`（完整正文与实验步骤）、`LAB_VERIFIED`（配套代码及干净环境复现）、`REVIEWED`（人工内容审校）、`LESSON_READY`（可转换教案）。写了文档不能自动升为后几种状态。

接力必须报告实际完成的文件、实际执行的检查、未解决事项、下一任务和禁止修改范围。课时安排、教学日历、学校教案表格等在转换阶段落实；不把设计稿提前包装成正式教案。
