## 统一视觉样式

使用白底、深蓝文字、少量浅色区域。每幅图先解决一个教学问题，再决定节点和箭头；复杂条件回到正文解释。颜色之外保留文字、实线/虚线和图形层级，避免仅靠红绿区分。

| 元素 | 约定 |
| --- | --- |
| 画布 | 常用宽 1280 px，按内容决定高度；四边留白至少 48 px |
| 中文字体 | PingFang SC → Noto Sans CJK SC → Microsoft YaHei → Heiti SC → sans-serif |
| 标题 | 32 px 左右，尽量一行；图号与“教学示意”置于标题上方 |
| 节点文字 | 常用 21—28 px；过密则拆图，禁止只缩小字号塞满 |
| 主文字 | 深蓝 `#17334b`；次要说明 `#526b7c` |
| 前端/普通流程 | 浅蓝 `#edf4fb`，边框 `#487ca4` |
| 后端/本地业务 | 浅青 `#edf7f4`，边框 `#558c7e` |
| 数据源/辅助对象 | 灰蓝 `#f3f6f9`，边框 `#8da6b8` |
| 选做/约束提示 | 浅金 `#fff5df`，边框 `#b58429`；选做用虚线并写明“选做” |
| 连线 | 2—2.5 px；动作或读写方向用箭头标明；跨线过多则调整布局 |
| 证据标签 | 图内或图注写“教学示意/教学界面示意”，不称运行截图或实验已通过 |
| 导出 | 可编辑 `.mmd` 或 `.svg` 源；配套 `.svg` 成品及 2 倍分辨率 `.png` |

公共图 01 示范手工 SVG，公共图 02 示范 Mermaid 时序图。两图不是章节配图数量的替代品。最终每章仍至少 3 幅独立 `chNN-*` 教学图。

## 当前本机运行条件

本轮实际使用 Node 26.3.0、Mermaid 11.12.2、Playwright 1.62.1、marked 17.0.5 与 Chromium 149.0.7827.55。Mermaid 由本目录 `package-lock.json` 固定；marked 和 Playwright 复用 Codex bundled runtime。首次在本机执行过 `npm install --ignore-scripts --no-audit --no-fund`。

脚本优先查找 `tools/node_modules`，然后使用 `COURSE_NODE_MODULES`，最后查找本机 Codex 缓存。浏览器优先使用 `COURSE_CHROMIUM_PATH`、当前 Playwright 路径，再发现本机已有 Chromium 缓存。它不连接用户登录浏览器，不启动现有业务服务，也不需要 HTTP 服务。

迁移到另一台机器时，先用 `load_workspace_dependencies` 查找可用 Node 和库；必要时设置 `COURSE_NODE_MODULES`、`COURSE_CHROMIUM_PATH`。`npm ci` 只恢复本目录锁定的 Mermaid 依赖，marked 和 Playwright 仍须由运行库提供。跨平台字体和浏览器可能改变排版，需要重新打开 PNG 核对。

## V0.3 最终生成

先确认正文及编入的资料已冻结，再执行以下命令。原有 40 幅图没有变化时无需重渲染；生成器只读取原图。V0.2 单文件不能作为输出目标。

```sh
# 默认读 manuscript/01—12*.md、阅读指南和十份常用资料。
# --strict 要求 12 章齐备且每章至少 3 幅对应 chNN-* 图片。
node tools/build-reader.mjs --strict

# 整书固定入口为 reading/index.html；相对引用 ../illustrations/。
node tools/verify-reader-round2.mjs --input reading/index.html --output illustrations/qa/round2-book

# 正文、常用资料、40 幅 PNG 及配套 SVG 内嵌。
node tools/build-reader.mjs --strict --embed-images --output reading/AI编程图文稿_V0.3_单文件.html
node tools/verify-reader-round2.mjs --input reading/AI编程图文稿_V0.3_单文件.html --output illustrations/qa/round2-standalone
```

阅读版含章级目录、紧凑章内定位、折叠资料目录、图表目录和图片大图入口。手机主目录默认收起，桌面默认展开；章内定位从真实标题生成，并识别现有小节中的验收表及接力段落，不改正文标题。中文 text 示例正常折行；程序代码保留缩进、横向滚动和键盘焦点，并显示语言及用途。代码展示逐块与源稿核对，不能因样式处理改动示例文字。

Markdown 源稿只读，完整章首 YAML 从显示内容剥离，原文件 SHA-256 记入构建报告。默认编入课程大纲、教学接口约定、考核与验收、48 学时实施分工、课堂任务单、AI 任务卡、AI 接力包、需求追踪表、Qwen 说明和教师资源制作清单；它们与章内 Markdown 链接转换为书内锚点。构建记录列出 23 份输入、资料数量和剩余文件依赖，验证器拒绝源稿与构建哈希不符的输入。

普通版点击图片打开 PNG 大图；单文件版点击图片保存 PNG，大图和 SVG 的下载不依赖旁边的目录。十份常用资料已内嵌，其余包内文件标“需完整资料包”，课程外参考标“需原项目”，外部网站仍需网络；这些限制在封面和对应链接旁说明。单文件 HTML 不等于整个编辑工程。窄屏适合连续阅读正文；复杂时序图应放大或保存大图查看。

`--strict` 的数量检查不代替内容审校。本轮三组交叉审阅覆盖 12 章原稿与 38 幅原图，统稿修订后再次实际看图；报告见 `handoffs/peer-review-*.md` 及最终交接。`prepare-book-figures.py` 是一次性冻结和初次插图辅助工具，不应在已统稿文稿上重新运行无参数准备步骤，否则会覆盖当前图元信息。

## 图源格式

每图一个主源，命名为 `ch03-01-短图名.mmd` 或 `ch03-01-短图名.svg`。公共样图使用 `shared-*`；不要用公共图填充章节三幅图的最低数量。

Mermaid 写纯文本语法，不带 Markdown 围栏，不嵌入 `%%{...}%%` 初始化指令或 YAML 主题。统一主题位于 `mermaid-theme.json`；节点文案简短，换行使用 Mermaid 支持的语法。若某类图含 HTML 标签或 foreignObject，需要统稿阶段改为纯 SVG 文字。

手工 SVG 必须有合法 `viewBox`、`title`、`desc`、真实 `<text>` 元素和明确尺寸；可参照公共图 01。禁止脚本、事件处理器、foreignObject、位图嵌入、远程字体/样式或外部引用。图中若没有统一图号、图题和证据标签，应先修订 SVG 源再导出。

宽图或长流程使用同名 `.figure.json` 的 `renderSource` 指向 `figure-sources/layouts/` 下的 SVG，实际渲染采用该版式；原 `.mmd` 保留逻辑关系。逻辑改动必须同步两者。固定 SVG 由 `make-fixed-layouts.py` 生成，布局修改应修改该脚本再生成，避免下一次运行覆盖手工补丁。

建议为每幅图提供同名 `.figure.json`，用于图题、替代说明及图注。缺少元数据的 Mermaid 暂用文件名作图题，统稿时必须补齐：

```json
{
  "id": "图 03-01",
  "title": "一句话说明本图要解释的关系",
  "alt": "说明主要对象、箭头方向和关键边界，不能只写图号。",
  "caption": "图 03-01　图题。解释读图顺序及结论；教学示意，非运行证据。",
  "evidenceKind": "TEACHING_SCHEMATIC",
  "labVerified": false
}
```

正文图片独占一个段落，并在相邻正文引用图号。替代文字描述图的意义；不要只写“图片”或文件名：

```markdown
图 03-01 说明前端请求如何经过后端授权边界。

![前端通过后端访问业务与数据源，最终授权在后端完成](../illustrations/ch03-01-短图名.png "图 03-01　请求边界。教学示意，非运行证据。")

读者应沿箭头指出各层负责的工作，并解释为何前端不能直接连接外部数据源。
```

生成器图注优先采用 `.figure.json` 的 caption，其次采用 Markdown 图片 title，最后用 alt。缺失图片、PNG 格式错误、SVG 配套缺失、同图重复插入、替代文字不足、原始 Mermaid 代码块、失效本地链接及缺章会阻止写出；外部项目参考仅提示。

## 实际检查和交付边界

渲染报告 `illustrations/render-report.json` 记录逻辑图源、版式图源和成品 SHA-256、尺寸、有效字号与超出画布的文字。它把人工/图像查看状态保留为待核对；本轮实际查看结论另存 `illustrations/final-visual-review.json`。`sample-visual-review.json` 仅适用于历史样张，不自动适用于重渲染后的图片。

两种阅读版均已在 Chromium 149 的 1440 px 和 390 px 视口检查：40 图加载、图注与替代文字、12 个章节目录实际点击、锚点唯一性、无横向文档溢出、无远端资源依赖、无页面脚本错误。单文件版另验证 PNG 下载 SHA-256。截图前等待图片解码与绘制，避免快速跳章时截到尚未绘制的白色图片区域。报告不代表真实手机、其他浏览器或印刷验收。

第一阶段曾打开两幅 PNG、桌面与窄屏截图及全部 6 页打印样张，修复 Mermaid 图框丢失 SVG id 和编号对比度。Poppler 对该历史打印样张报告过两次 Type 3 字形包围盒警告，实际页面未见缺字或裁切。第二阶段使用 `--skip-pdf`，未生成或宣称完成整书 PDF 审校。

交付文档包不要包含 `tools/node_modules/`（本机约 129 MB）、`tools/.cache/` 或浏览器运行库；保留 `package.json`、`package-lock.json` 和脚本以便重建。`illustrations/qa/` 属于验收资料，可单独保留，不计入全书 40 幅教学图。联系表 HTML 使用本机文件路径，只作本机检查；图文阅读入口不依赖这些联系表文件。
