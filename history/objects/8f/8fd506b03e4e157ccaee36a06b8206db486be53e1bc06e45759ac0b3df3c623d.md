# Qwen 与网页工具说明

核对日期：2026-10-18。本课程用网页对话支持软件工程学习，以 Qwen3 为模型案例；工具和型号可变，项目合同、学生理解和运行证据保持稳定。

## 区分产品模型与工具

| 名称 | 含义 | 课程用法 |
| --- | --- | --- |
| 千问/通义网页 | 面向用户的聊天产品 | 学生实际操作入口 |
| Qwen3 | 阿里 Qwen 团队的通用模型系列 | 讲解提示、上下文、生成与核验 |
| Qwen3-Coder | 面向代码的模型系列 | 比较能力的进阶例子 |
| Qwen Code | 编程工具，能够结合文件与命令工作 | 仅选学，不是网页主线的前置条件 |

型号与系列含义参考 [Qwen3 官方仓库](https://github.com/QwenLM/Qwen3)、[Qwen3-Coder 官方仓库](https://github.com/QwenLM/Qwen3-Coder) 和 [Qwen Code 官方说明](https://qwenlm.github.io/qwen-code-docs/zh/users/quickstart/)。不将“使用千问网页”写成“固定使用某个 Qwen3 型号”。

## 学生如何开始

使用 [千问官方网页](https://www.qianwen.com/) 或学校选定的其他国内聊天工具，按产品正常流程登录。教师在开课前用学生同等账号条件检查校园网络、代码块复制和常规任务可用性。

实际模型选择、额度、附件和联网功能以学生账号界面为准。记录平台、日期、界面显示的模型名；没有显示就写“未显示”。课程不承诺永久免费、无限额度或每人可选择 Qwen3-Coder，也不要求学生购买 API。

网页 AI 可能无法查看本地文件、运行代码或保持长期上下文。主线始终用“复制上下文 → 生成局部改动 → 本地执行 → 回传真实结果”的方式，并按 [协作规范](../03-AI协作与接力规范.md) 保存接力记录。

## 一次课堂工具检查

让学生把一段不含个人信息的简单函数和两个输入发给模型，请其预测结果、指出边界并建议测试；学生在本地运行，对照预测。随后再发一个真实错误，要求模型先说明原因，再提出最小修复。这个练习同时检查账号可用性和学生对“回答不等于执行”的理解。

若遇到限额或网络故障，使用教师预备的离线“模型回答、代码片段、错误日志”继续进行审查与调试，不影响核心目标。学生不能为解决额度问题将同学账号或密钥写进项目。

## 可选接入路线

后续具备资源时可了解百炼兼容 API、Qwen Code 或本地模型，但需要单独核实访问条件、费用和运行要求。这些路线不应出现在必修实验的隐藏步骤中。[百炼官方兼容接口说明](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope) 可作为扩展阅读；具体模型标识和端点以当次官方配置为准。

不用模型排行榜替代课堂验证。比较两个模型时，使用相同上下文、任务与独立验收，报告正确性、修复轮次、遗漏和学生理解成本，不凭一次回答给整个模型系列下结论。
