# 教学接口约定

本文件规定课程各章使用的共同语义。独立教学实现位于 `resources/campus-ai-course`，原始参考为 [现有系统接口合同](../../../system/docs/api-contract.md)。原平台代码与合同不因课程改动而修改。

## V1.0实现入口

`first-chain`保留第04章一空间两设备读取与无数据库登录基础；`teacher-db`实现4空间、16设备、28点、空间映射、质量与历史、事件、责任和时间线。完整路由、请求字段及错误标识见 [机器可读HTTP合同](../resources/campus-ai-course/backend/docs/full-api.json)。实际入口均以 `/api` 开头，下表省略该前缀用于业务说明，Vite代理保留它。

教学认证为会话Cookie+CSRF，四个本地账号由初始化器随机生成。权限由后端按当前有效身份决定；teacher-db读取当前数据库角色，使撤权在后续请求生效。第04章的校园写入桩仍返回501；从第05章开始必须切换 `backend-db` 并使用已迁移的课程库。

数据源通过 `COURSE_SOURCE=TEACHING_MOCK|AIRIOT` 显式选择。必修使用TEACHING_MOCK；AIRIOT为保留的只读扩展组件，尚未实现真实连接，选中后明确不可用，不能悄悄回退模拟。远端控制与外部通知始终关闭。代码和作者验证不等于学校环境与学生实测通过。

## 通用约定

成功响应使用 `{code:0,message,data}`；HTTP 状态与业务状态分开。参数无效 400、身份无效 401、权限不足 403、对象不存在 404、版本或状态冲突 409。上游异常由后端转为适当的 502/503，不转成前端登录过期。

读取接口均在认证后的校园角色范围内。学生第一次贯通使用教师准备的教学登录基础；临时调试身份不能成为交付时绕过认证的入口。身份、操作者和系统时间由后端确定，不相信前端提交的 actor 或时间。

所有时间为 epoch 毫秒；布尔权限只有 JSON Boolean `true` 授权；分页、时间窗和字段类型明确校验。响应不得出现 API Key、token 或密码。

## 教学版与现有合同的明确差异

`source` 扩展为 `TEACHING_MOCK | AIRIOT`，并同步后端 DTO、前端类型和测试。模拟实现返回 `TEACHING_MOCK`，真实适配返回 `AIRIOT`。模拟对象另标 `simulated:true`，二者不可互相替代。其余核心字段和规则尽量保持参考合同语义。

教学历史样本显式扩展为 `HistorySample={time:number,value:number|null}`。`time` 是有效的 epoch 毫秒整数；`value` 是有限数值，或来源明确返回的缺失标记 `null`。Java 教学 DTO 使用 `Double` 表达可空值，TypeScript 使用 `number | null`。现有参考系统的 `CampusDtos.Sample` 为 `double`、`HistoryResult.samples.value` 为 `number`，不能直接复制为本课程的类型；这属于已在教学工程实施的明确差异。

有时间、无数值的原始样本保留为 `null` 断点，不算有效测量，也不补零。完全没有返回样本的时刻不创建记录。字符串数值、布尔值及非法时间不冒充合法样本；非有限数值不能写成 JSON 的 `NaN` 或 `Infinity`。数据源适配层应拒绝或按冻结的异常规则报告非法输入，不能无说明地转成 `null`。异常条目冻结为 `{code,message,scope}`。先校验每条原始记录的时间与值类型，非法条目跳过并报告 `HISTORY_INVALID_SAMPLE`；合法记录按闭区间from/to过滤，同时间重复项保留最先出现者并报告 `HISTORY_DUPLICATE_TIME`；按时间升序后取前1000条，有更多合法唯一时间项时truncated=true。明确返回的null保留。

数据源接口已冻结为 `CampusProvider`：`spaces()`、`devices()`、`latest(deviceId)`、`history(deviceId,tagId,from,to)`、`alarms(limit,skip)`、`status()`。业务服务依赖端口，`MockCampusProvider`读取固定夹具；`AiriotReadOnlyProvider`保留只读扩展接口并显式报告未配置。前端不直接请求AIRIOT。

空间写入的错误语义也按教学合同统一：格式正确但引用的校园、楼栋或空间不存在，返回 404；空名称或不合法字段返回 400。现有参考 `CampusLocationService` 对部分不存在引用返回 400，移植为教学版时须连同测试改为上述规则。此差异不修改原平台，也不把名称判空等参数错误改成 404。

## 核心读取对象

| 对象 | 关键字段 | 规则 |
| --- | --- | --- |
| Space | id、name、type、campusId、buildingId、floor | 映射字段可空，映射只存本地 |
| Device | id、tableId、name、category、spaceId、online、communicationTime、simulated、tags | online 可为 null；category 为 environment/energy/facility/lighting |
| Point | deviceId、tableId、tagId、value、time、quality、unit | value/time 可空；quality 为 fresh/stale/missing/invalid |
| History | source、deviceId、tagId、unit、from、to、observedAt、samples、truncated、issues | samples 使用上述 HistorySample；原始 null 保留，不创建未采样时刻 |
| Capability | roles、canRead、canControl、canAdmin、canAudit、canHandleAlarms、canAssignAlarms、canRunDemoScenarios | 基础教学中 canControl 一律 false |

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "source": "TEACHING_MOCK",
    "deviceId": "teaching_energy_01",
    "tagId": "power",
    "unit": "kW",
    "from": 1000,
    "to": 3000,
    "observedAt": 3000,
    "samples": [{"time":1000,"value":0},{"time":3000,"value":1.2}],
    "truncated": false,
    "issues": []
  }
}
```

上例时间为缩小的教学样例；实际数据使用真实格式的 epoch 毫秒。1000 与 3000 之间没有样本，图表不据此声称发生过 2000 时刻的测量；允许视觉连线时须保留采样语义，缺失或无效数据按断点处理。

## 接口模块

| 模块 | 主要接口 | 学生任务 |
| --- | --- | --- |
| 能力 | GET /campus/capabilities | 服务端能力与前端入口一致 |
| 监测 | GET /campus/overview、/spaces、/devices | 读取和聚合，实际数量与质量 |
| 空间 | GET /campus/locations；POST /campus/locations/campuses、/buildings；PUT /campus/locations/spaces/{spaceId} | 仅管理员写、本地持久化与关联校验 |
| 历史 | GET /campus/history | deviceId/tagId/from/to 合法性、原始样本 |
| 原始报警 | GET /campus/alarms | 只读，空列表不代表机制已验证 |
| 事件 | GET /campus/alarm-cases 及 /{id}、/handlers；POST /{id}/assign、/start、/notes、/verify-recovery、/close | 状态、本人范围、版本和时间线 |
| 演练 | GET /campus/demo/status；POST /campus/demo-alarm-scenarios/{scenario}/trigger；POST /campus/demo-alarm-events/{id}/recover | 仅本地 DEMO，触发/恢复仅管理员 |
| 责任 | GET /campus/device-owners 及 /{deviceId}；PUT /campus/device-owners/{deviceId} | 有效负责人、版本和责任时间线 |

表中事件操作的 `/{id}` 均接在 `/campus/alarm-cases` 后；演练恢复接口的 id 也是 AlarmCase.id。第 04 章最小桩和后续实现须使用同一合同，不另建一套无法演进的接口。

## 角色矩阵

| 操作 | ADMIN | CAMPUS_MANAGER | CAMPUS_VIEWER |
| --- | --- | --- | --- |
| 读取校园与演练记录 | 允许 | 允许 | 允许 |
| 空间/责任登记、分派、演练触发及恢复 | 允许 | 拒绝 | 拒绝 |
| 开始、记录、核实和关闭 | 所有合规事件 | 仅本人已分派事件 | 拒绝 |
| 远端设备控制与外部通知 | 关闭 | 关闭 | 关闭 |

角色资格以当前有效账户和启用角色为依据。实际认证组件可保留原系统更多管理员角色，但不改变以上课堂角色矩阵。禁用账户、撤销角色和对象范围检查必须在后端生效。

## 状态和并发

事件业务状态为 NEW、ASSIGNED、IN_PROGRESS、CLOSED；来源状态为 ACTIVE、RECOVERED、UNKNOWN，两类状态分别保存。触发场景创建独立 DEMO/LOCAL_DEMO 事件；有有效设备责任人时可以自动进入 ASSIGNED。

关闭需同时满足：处理中；至少一条处置记录；演练来源已经恢复；服务端独立核实 PASS 且核实时间有效；有非空结论；操作者获准；expectedVersion 匹配。已关闭事件不可修改。重新分派未关闭事件回到 ASSIGNED，旧记录保留，新负责人重新开始。

`expectedVersion` 为非负 JSON 整数，不接受字符串或布尔值。写操作在同一数据库事务中锁定当前记录、核对版本、修改主记录并追加时间线；旧版本返回 409。该参考方案是行锁配合版本检查，不能在讲义中误称纯乐观锁更新。教师也可设计有充分测试的替代方案，但需统一合同和实现解释。

版本字段仅适用于合同规定的事件更新与责任登记。场景触发为空 body 或 `{}`，创建版本为 1。版本匹配、未关闭且已经恢复的事件再次执行恢复，返回当前详情，不重复增加版本或时间线；关闭后的事件仍禁止修改。

设备责任初始 version 为 0；修改后递增并保存时间线。责任人变更影响未来事件的自动分派，不改写已经生成事件的 assignee。并发冲突和时间线失败回滚需真实数据库证据。

## 教学参数与夹具基线

以下参数已用于教学工程，与原系统分开维护。若调整，先更新合同、夹具和测试，再更新正文。

| 项目 | 教学基线 |
| --- | --- |
| 最新值刷新 | 一轮完成后等待 15 秒再发下一轮；离页停止 |
| 质量时钟 | 后端使用可控教学时钟，前端显示结果，不自行改质量 |
| 过期阈值 | 合法采样距观察时间超过 60 秒为 stale，等于 60 秒仍 fresh |
| 未来时间 | 超过观察时间 5 秒为 invalid；5 秒以内以时钟容差处理，保留原始采样时间 |
| 缺失与无效 | 优先判断非空值/时间的非法类型或范围为invalid，再判断缺失为missing，随后判断未来容差与陈旧阈值；不转换为零 |
| 历史 | 课堂默认 15 分钟/1 小时，最大跨度 6 小时，每次最多 1000 样本；截断标记必须准确 |
| 第一条贯通 | teaching_space_01，teaching_env_01，teaching_energy_01 |
| 温度巡查 | temperature-patrol 在教学版引用 teaching_env_01；不使用原演示项目设备 ID |
| 权限夹具 | 至少 ADMIN、MANAGER A、MANAGER B、VIEWER 四个身份，三种角色 |

撤销管理资格的独立实验使用同一 ADMIN 教学身份的专用初始角色集合 `[ADMIN, CAMPUS_VIEWER]`。撤销 ADMIN 后仍有读取资格，预期读取 200、管理写入 403；实验结束恢复完整初始集合。此配置只服务于隔离教学夹具，不更改原系统角色，也不把“禁用账户”与“撤销角色”混为一项测试。A、B 保持管理人员身份，VIEWER 保持只读身份。

完整空间与设备清单、每点单位和时间序列已在教师资源包fixtures中冻结。缺失、无效等样例应独立设置，避免同一条样例同时触发多个条件而无法判断预期。

## 审计范围

必修审计通过事件 timeline 和责任 timeline 展示 actor、action、time、version 等服务端事实。现有 `/campus/audit` 主要承载模拟开关操作，不能直接当成新课程所有业务的通用审计接口。若增加独立综合审计页，需另行定义来源及合同，作为进阶范围。

## 版本与读写一致性

事件列表先筛选后计数和分页，按createdAt降序、id降序稳定排列。事件详情、责任详情、空间映射复合读取在只读事务内取得一致快照。写事务执行行锁、当前版本检查、主行更新和时间线插入，任一异常均越过事务边界回滚。

第11章真实MySQL测试仅可访问教师明确授权清理的独立测试库；故障注入只装配在测试上下文，没有HTTP故障入口。作者验证报告与学生的独立证据分别保存。
