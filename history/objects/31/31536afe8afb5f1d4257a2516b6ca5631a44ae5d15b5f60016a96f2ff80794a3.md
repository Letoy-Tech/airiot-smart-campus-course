# V1.0.1 第五轮复查与修订验收

2026年10月19日。本轮对已交付教程进行独立交叉检查，范围为教学目录。原 `system/` 平台、学校数据库和真实 AIRIOT 未修改。V1.0及更早压缩包保留原哈希；当前阅读版、参考工程、分章起点和教案同步为V1.0.1。旧报告只证明当时的版本。

## 本轮修正

| 范围 | 复现的问题 | 修正后的行为 |
| --- | --- | --- |
| 事件详情 | 新建事件后，旧详情迟到响应可覆盖新事件 | 新建接管详情时取消旧请求；迟到成功、403和普通错误均不能污染新事件，分派输入重置 |
| 事件与责任权限 | 列表403后旧详情和写入口仍可能保留 | 清理列表、详情、选中项和输入，取消相关请求；提示重新核对身份，不自动重发 |
| 请求期限 | 操作单提到超时，统一请求却没有期限 | 请求及响应体读取统一15秒期限；支持外部取消，清理定时器；写入结果不确定时先回读 |
| 设备空状态 | 成功空目录与筛选无匹配使用同一提示 | 根据原目录是否为空区分两种事实 |
| 数据库读取 | READ COMMITTED连接下，聚合读取可能混合主记录与时间线版本 | 多查询聚合显式使用REPEATABLE_READ，同一事务读取一致快照 |
| 历史单位 | 历史夹具单位被改为V时，数值仍被直接标成kW | 加载时核对历史、目录标签和单位，不合法则拒绝，不改标签冒充换算 |
| 时间合同 | 目录接收超过合同范围的时间戳，质量判断却拒绝 | 复用统一时间范围校验 |
| Windows配置 | UTF-8 BOM导致教师JSON工具解析失败 | 统一私密JSON读取入口兼容BOM，错误不回显配置内容 |
| 第02章 | 正文、教师答案、教案的R01验收情境不同 | 统一为正常两条、成功空数组、读取失败；未知通信与未登录另列后续阅读 |
| 第04章及后续起点 | 工程路径缺少可执行Git基线步骤 | 新副本先核对忽略规则和待提交内容，再建立基线；不重新初始化已有本人仓库 |
| 第05、07、08章 | 可复制AI提示超出对应C05/C07/C08任务 | 明确本章最小修改、预期反例和验证范围 |
| 第10章 | 本人/非本人NOTE对照缺少开始处理步骤 | 先使事件进入IN_PROGRESS，再执行403/200对照 |
| 第12章 | 未完成C12的起点被要求先全检/复现 | 先预测并补C12、针对性回归形成B，再全检、打包和交叉复现 |
| 第12章分页 | 4条/limit=2的API规格被混同为页面分页数据 | 给出独立空库14条事件的教师准备步骤，形成NEW12/ASSIGNED2/IN_PROGRESS0；页面每页10条 |
| 第12章恢复图 | 图12-03仍将未完成的基线A作为恢复对象 | 图源、生成器、SVG和PNG统一改为恢复已核验代码，并实际检查新图 |
| 阅读资源链接 | 第08章到第05章工具的标题片段被编码成文件名 | 嵌入资料之间使用真实锚点；检查本地文件存在并实际点击跨章链接 |
| 作者构建工具 | marked/Playwright未明确声明，依赖作者Codex缓存；Python依赖缺少说明 | 锁定本地依赖、移除隐式缓存回退，补Python清单及维护步骤；旧版阅读文件禁止覆盖 |

第12章的14条数据是可执行的课前准备流程，本轮没有将说明伪写成已在课堂执行。教师须使用独立演示库并记录实际准备结果，不能删除学生历史数据来凑数量。
