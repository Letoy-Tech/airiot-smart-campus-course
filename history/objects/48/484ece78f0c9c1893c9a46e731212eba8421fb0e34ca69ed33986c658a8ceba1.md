# 第04站 Ask 结论（操作者据 CodeBuddy 回答摘录）

校园 id/name → 楼栋 id/name/campusId；来源空间只读 id/name，通过绑定 spaceId/buildingId/floor 关联，campusId由楼栋推导。先建校园，再建楼栋，最后绑定已有来源空间。不存在的楼栋或空间应404并保持旧关系；只有 canAdmin === true 显示保存入口，后端最终鉴权。

# 第06站 Ask 结论（操作者摘录）

历史必须带deviceId、tagId、from、to，毫秒时间范围最多6小时。null在原采样时刻断线，0为有效样本。原始报警只读保留status/level，与本地演练事件并列，不用演练状态替换上游状态。
