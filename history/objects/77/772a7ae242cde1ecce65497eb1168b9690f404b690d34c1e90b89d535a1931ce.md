# 第 05 课：把历史和原始报警接到页面

本课 4 学时，共 180 分钟。我们给设备详情加一个“查看历史”入口，让它真的打开对应设备、对应点位的曲线；然后完成原始报警页。

五步建议用时依次为 30、45、30、40、35 分钟，共 180 分钟。这是备课建议，并非课堂实测；教师可按实际卡点调整。

继续原来的 `campus-lab`，让终端 **A-页面** 保持运行。数据仍来自同一份公开练习资料，不需要后端。

先记住：**原始报警页展示收到的报警内容；演练事件页记录我们自己练习处理的事项。**本课先做前者，下节课再做后者。

**重新开课：** 打开原 `campus-lab`。若 A 已结束，在项目根的 A-页面运行 `node tools/serve.mjs`，再用上次的同一个浏览器打开 `http://127.0.0.1:5188`。若页面已能打开，就沿用原 A，不重复启动。本课不启动 Java、MySQL 或 Redis。

## 第 1 步：先从详情打开正确的历史表

**现在在哪：**CodeBuddy 对话框。先把入口接通，再画图。

```prompt
继续当前项目，只完成第05课第1步。读取materials/约定卡.md，在已有设备详情中为每个实际点位增加“查看历史”按钮。
点击后进入现有历史菜单，使用 #history?deviceId=实际ID&tagId=实际点位 的地址片段保存选择。
历史页通过getOverview返回的history，按deviceId和tagId共同找数据。先显示设备编号、设备名称、点位、单位及样本表；样本表列出原time和value，null显示缺失、0保留。
没有匹配历史时显示“这个点位没有历史样本”，不要默认拿第一台或第一条历史代替。直接点击历史菜单而未选设备时，显示设备和点位选择框。
保留详情、筛选和所有旧页面。保存文件，不启动服务，不画图。
```

**等到什么：**等 AI 保存完成，浏览器刷新。

**自己点看：**打开设备 `d05` 的详情，找到功率，点“查看历史”。

**应该看到：**历史页明确写出 `d05`、功率 `power` 和 kW；表格里的时间来自样本。浏览器地址中的设备和点位也是刚才选中的内容。

**如果打开了别的点位：**单独发送：

```prompt
第05课第1步从d05功率进入历史后，显示的设备或点位不对。请检查按钮传入的deviceId、tagId、地址片段解析和历史查找，只修复这条入口。必须同时按两个字段查找，不默认第一条，不修改样本。
```

入口正确后，进入第 2 步。

## 第 2 步：把历史表画成曲线

**现在在哪：**CodeBuddy 对话框。表格已经正确，曲线必须与它使用同一批数据。

```prompt
只完成第05课第2步。在现有历史页样本表上方增加简单曲线，使用浏览器自带SVG或Canvas，不安装图表库。
曲线与表格使用同一个history.samples数组，按原time排序；横轴是采样时间，纵轴是值和原单位。
横轴首末时间刻度须完整显示，按两端位置设置对齐并预留边距，不能被SVG或容器裁剪；窄屏下仍能辨认。
数值0是有效点，必须画出来；value=null处断开，不画成0，不跨过缺失点把两侧连起来，不补造样本。
每个有效点能查到时间和值。没有有效样本时显示文字，单个有效点也要能看见；全部有效值都是0时也能正常绘制，不因坐标范围为0而消失。
保留下方完整样本表作为对照，显示“固定教学样本”。保存文件，不启动服务。
```

**等到什么：**等 AI 保存完成。刷新浏览器，再进入 `d05` 的功率历史。

**自己点看：**先读表格中的样本，再看图；找到数值 0 和缺失的那一行。

**应该看到：**0 在图上有点；缺失位置断开；图与表的设备、点位、单位一致。图没有把缺失画成一段突然掉到 0 的线。

**如果缺失处仍被连过去：**单独发送：

```prompt
第05课第2步的历史曲线跨过了缺失样本。我将说明对应时间。请把连续有效样本分段绘制，遇到null断开，保留真实0。只修复绘图，不删表格、不填补数据、不改原始历史样本。
```

图表能互相对照后，进入第 3 步。

## 第 3 步：选择查看哪一段时间

**现在在哪：**CodeBuddy 对话框。我们的练习时间固定，不能把“最近 15 分钟”误认为今天的真实时间。

```prompt
只完成第05课第3步。在历史页增加“全部样本”“样本末时刻前15分钟”“样本末时刻前1小时”三个范围选项。
历史页始终显示设备和点位选择框，包括从详情链接进入时；选项与地址中的deviceId、tagId一致，切换后同步更新地址，方便直接从功率改选电压。
以当前所选历史的最大time作为样本末时刻，显示这个实际时刻。根据该范围过滤样本，图和表共用筛选后的数组。范围内没有数据时显示“这个范围没有样本”，不是读取失败。
切设备或点位时重新计算末时刻，更新标题和单位，不能沿用上一台设备的曲线。刷新浏览器后保留地址中的deviceId与tagId；范围默认全部样本即可。
新增的范围状态和选项常量，要在页面构造和首次读取之前定义、初始化，不能在首次使用时仍未定义。语法检查通过不等于刷新后的页面能运行，请保留由我亲自刷新验证的步骤。
保留缺失断线和0，保存文件，不启动服务。
```

**等到什么：**等 AI 保存完成，刷新浏览器。

**自己点看：**在 `d05` 功率历史中来回切换三个范围；然后改选同一设备的电压。

**应该看到：**每次图和表都使用同一时间范围；页面写出的末时刻属于固定样本日期；换成电压后标题和单位变为 V，功率的旧曲线消失。

**如果刷新后页面一直停在“正在读取”：**先查看浏览器控制台的第一条错误，只复制错误文字，不复制口令或私密配置。单独发送：

```prompt
第05课第3步保存后，刷新页面一直停在正在读取。实际地址片段是【片段】，浏览器控制台第一条错误是【错误】。
请先修复这条使页面无法初始化的运行错误，检查新增范围状态和选项是否在首次使用前定义并初始化。保留原样本、原页面和地址中的设备/点位选择，不启动服务。修好后让我重新执行本步全部点击，不把语法检查当成浏览器验证。
```

**如果换点位后还残留旧曲线：**单独发送：

```prompt
第05课第3步换设备或点位后仍有上一次的曲线。请只修复历史页的选择更新：先确定当前deviceId/tagId，再计算本次时间范围并替换图和表。不能把旧数组与新数组拼接。保留地址中的选择。
```

范围和点位切换正确后，进入第 4 步。

## 第 4 步：回到能源页，比较同一种读数

**现在在哪：**CodeBuddy 对话框。这一步既要写比较区域，也要把它放进已经完成的能源页。

```prompt
只完成第05课第4步。继续原有能源页，在功率/电压选择框下面加入“比较历史”区域，实际显示在页面中，不能只生成一个未使用的函数。
列出四台category===energy设备的复选框，允许选1至4台，点击“比较历史”后读取getOverview中的对应历史并展示。
当前选功率就只比较power/kW，选电压只比较voltage/V。每台曲线有名称和样本时间；缺失仍断线，0保留。
一台没有历史时，在那台旁边写“没有历史样本”，保留其他有样本设备的结果。不能拿另一台数据替代。切功率/电压后清掉旧比较和设备勾选，提示“请重新选择设备，再比较”，防止旧曲线换个单位继续显示。
保留本页四台最新读数和查看设备入口。保存文件，不启动服务。
```

**等到什么：**等 AI 保存完成，刷新浏览器，点击“能源”。

**自己点看：**选择功率，勾选 `d05` 和 `d06`，点“比较历史”；再切到电压，确认旧结果和勾选已经清空，重新勾选 `d05`、`d06`，再点“比较历史”。

**应该看到：**功率比较中两台都用 kW；切电压时旧比较先清除，重新比较后都用 V。设备名单只有四台能源设备，没有环境设备。

再看两张图最左与最右的采样时间，确认文字完整。若末端时间被裁掉，单独发送：

```prompt
第05课第4步的比较功能能用，但图表两端时间刻度显示不完整。实际窗口大小是【大小】，被裁掉的文字是【文字】。
请只修复共用绘图的首末刻度对齐和留白，同时检查历史页与能源比较图。保留比较入口、单位切换后清空、缺失断线、0和原样本，不重建页面，不启动服务。修好后让我重复比较与截图检查。
```

**如果比较区域根本没出现：**单独发送：

```prompt
第05课第4步AI说写好了比较功能，但能源页面没有入口。请检查这个区域是否真正接入现有energy页面，补齐渲染和按钮调用。保留已有最新读数、单位切换和设备详情入口，不另建能源页。
```

比较区域能实际使用后，进入第 5 步。

## 第 5 步：完成只能查看的原始报警页

**现在在哪：**CodeBuddy 对话框。使用已存在的“原始报警”菜单。

```prompt
只完成第05课第5步。使用getOverview中的alarms完善现有原始报警页。
每条显示报警编号、设备名称及ID、message、原始status、原始level、原始time和“教学模拟”。status和level可附中文解释，但原始值也要保留，不能擅自替换成演练事件的状态。
增加文本搜索和每页5条的上一页/下一页，显示当前页与总数。搜索后回第一页；无匹配显示“没有符合条件的原始报警”。读取失败与没有匹配分开。
每条有“查看设备”入口，打开相应设备详情。本页没有分派、恢复、核实、关闭按钮，不修改alarms数据。
保留历史和能源比较功能，保存文件，不启动服务，不进入演练事件开发。
```

**等到什么：**等 AI 保存完成，刷新浏览器，点击“原始报警”。

**自己点看：**对照公开 JSON 中任意一条报警，检查编号、状态、等级和时间；搜索 `不存在的报警`，再清空；点一条报警的“查看设备”。

**应该看到：**原始字段保留；没有匹配时有明确文字；清空搜索后恢复列表；设备入口定位正确；页面没有“关闭原始报警”的操作。

**如果报警页出现处理按钮：**单独发送：

```prompt
第05课第5步的原始报警页出现了分派或关闭等处理动作。请只移除这个只读页面上的写操作，保留搜索、翻页和查看设备。不要删除原始报警样本，不要把它们转成演练事件。
```

完成后，在 `notes/05-历史和报警.md` 写下：从哪台设备的哪个点位进入历史；0 和缺失如何显示；原始报警页可以做什么、不能做什么。保存一张设备与点位清楚可见的历史截图。

**接下来：**让终端 A 继续运行，进入第 06 课。我们将单独创建演练事件，按步骤练习“发现、分派、处理、核实、关闭”。
