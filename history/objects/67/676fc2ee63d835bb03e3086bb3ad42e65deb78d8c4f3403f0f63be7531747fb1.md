# 教师资源制作清单

以下是从课程设计进入可授课实验的制作任务，当前状态均为待制作或待验证。现有线上平台可供教师理解目标，不能直接充当学生共享开发环境。

## 开课前必需资源

| 编号 | 资源 | 制作要求 | 验证条件 |
| --- | --- | --- | --- |
| T01 | 独立工程骨架 | Vue/TS 与 Java/Spring Boot；固定依赖和版本说明 | 干净环境能安装、构建和启动 |
| T02 | 身份基础 | 标准认证组件、三类教学账号、无真实凭据 | 401、403、禁用与角色变更路径可测 |
| T03 | 数据库环境 | 每组隔离、可复现的 MySQL 与迁移、无共享生产连接 | 重建、持久化和清理范围明确 |
| T04 | 教学数据源 | 显式 TEACHING_MOCK、固定种子、可控时钟 | 无 AIRIOT 账号也能读取数据 |
| T05 | 数据与故障夹具 | 正常、空、缺失、无效、过期、超时、部分失败 | 用固定输入得到可核对输出 |
| T06 | 业务模块模板 | 空模块、通用 DTO/请求样式、事务和表单示范 | 学生能专注业务判断，不陷入重复配置 |
| T07 | 测试工具 | JUnit/Vitest入口、API请求、并发屏障、回滚注入 | 真 MySQL 结果可独立回读 |
| T08 | 阶段检查点 | M1—M5对应代码与文档，教师参考答案单独存放 | 每个检查点可复现且变更清楚 |
| T09 | 离线 AI 材料 | 示例回答、缺陷代码、错误日志及参考评审 | 无模型网络时仍可完成审查任务 |
| T10 | 平台账号预检 | 学生同等条件的网页访问与代码复制测试 | 不依赖付费/API/附件高级功能 |

## 教师保留与学生获得的内容

学生获得起始骨架、合同、模拟数据、空模块、测试模板和逐章任务；教师保留完整参考实现、典型缺陷答案与评分依据。关键业务逻辑不能全部预填，至少给学生保留接口校验、查询与映射、UI 状态、业务授权、关闭门槛、版本处理和责任规则的实际实现工作。

共用表单、数据库连接、认证底层等重复配置可以提供。第 09 章需要统一动作与事务框架、第 11 章需要可直接使用的并发和故障注入模板，以使 4 学时集中在规则实现与证据解释。若试做仍超时，应进一步缩减页面数量和重复代码，不削弱关键工程验收。

## 待实测的运行约束

- 目标 Windows/macOS 环境、JDK 与 Node 版本是否统一可用。
- 学生能否安装依赖，机房是否允许容器，数据库采用本地还是教师隔离环境。
- 认证基础是否仍需 Redis，所需服务如何随脚手架启动和停止。
- 每组端口、数据库、种子和重置工具是否隔离；清理操作仅作用于本组教学数据。
- 依赖下载与网页 AI 限额问题是否有可用的离线材料和镜像安排。

这些事项须在制作脚手架时确认并实测；当前大纲不假定学校设备已有某个工具，也不把现有 macOS 脚本分发为跨平台方案。

## 资源版本记录

每个资源包记录资源版本、源代码标识、依赖版本、适用章节、运行环境、实际验证日期和已知问题。课程正文和教案引用该版本；资源变更后重跑受影响实验并更新截图及错误说明，保留旧版追踪信息。
