# 00 第一次用 AI 做项目：先学会一轮完整操作

你可以从“我只会打开网页”开始。这套00—12手把手教程带你走完构思、分析、设计、编码、调试、测试和交付。现在先不用安装编程软件或连接数据库；00—03先做出 **11份需求设计文件**，从04开始再把它们用于真实工程。

本篇教你第一轮网页AI操作。后面每篇都有真实文件位置、提示词、示例、人工检查与下一步。教师提供完整工程框架，学生逐章补局部业务并验证；不是让AI从空文件一次生成整个软件。11份文档只是开发依据，完成代码与实际运行后才形成平台作品。

## 先看清楚今天要做什么

我们用同一个例子走到底：校园值班人员打开网页，找到设备、看清模拟读数，再练习记录一次设备巡查。课堂使用 4 个模拟空间、16 台模拟设备、28 个采集点。“模拟”表示专门为教学准备的数据，不是某所学校现在的设备情况。

第一步只需要说清“谁遇到了什么麻烦”。后面的角色、需求编号、页面、数据和接口，都会逐步解释，不需要现在全部记住。

### 两个词先弄明白

- **提示词**：你发给 AI 的话，不是特殊程序。教程中绿色框里的整段话可以直接复制。
- **Markdown 文件**：后缀为 `.md` 的普通文字文件。里面的 `#` 表示标题，`-` 表示列表。看见这些符号是正常的，不用删掉。

文中的“AI 示例回答”是作者编写的教学样例，用来对照长度、内容和格式；它们不是实际登录千问后的调用记录，也不是唯一正确答案。你要保存自己和 AI 讨论后的版本。AI 如果说“已为你保存文件”，仍须按下面的方法自己下载和检查。

## 准备一：在桌面建两个文件夹

文件夹相当于放作业的文件袋。我们把所有产物放进同一个位置，防止下一步找不到。

**Windows：**

1. 按键盘上的 `Windows 键 + D`，回到桌面。
2. 在桌面的空白处点鼠标右键，选“新建”→“文件夹”。
3. 输入 `campus-ai-lab`，按 Enter。请照抄这个英文名字，里面是短横线。
4. 双击这个文件夹。在打开的窗口空白处再次右键，选“新建”→“文件夹”。
5. 输入 `docs`，按 Enter。

**macOS：**

1. 点 Dock 中蓝白笑脸的“访达”。在左侧点“桌面”。
2. 按 `Shift + Command + N`，新建文件夹；输入 `campus-ai-lab`，按 Return。
3. 双击进入它，再按 `Shift + Command + N`，输入 `docs`，按 Return。

若同名文件夹已经存在，直接打开，不删除原文件。现在你应该能打开“桌面→campus-ai-lab→docs”。暂时是空的，正常。

图 00-2：这是位置示意，不是你的电脑截图。你现在只需要建立蓝色的两个文件夹，文件稍后逐个产生。

## 准备二：同时保留教程和 AI 两个网页

1. 保留当前教程页。不要关掉，否则找不到下一步。
2. 点击这个链接：[打开千问网页](https://www.qianwen.com/)。它会打开另一页。也可以在浏览器地址栏输入 `https://www.qianwen.com/` 后按 Enter。
3. 若网页要求登录，请自行完成登录。我们不需要购买模型 API，也不需要填写 API Key。
4. 找到网页中的聊天输入框。已有旧聊天时，使用网页提供的“新对话”入口开启一段新聊天。入口的名称和位置可能随网页更新；本教程不依赖某个固定按钮坐标。
5. 点击输入框，输入下面这句练习话，点发送按钮。它通常是输入框旁的箭头图标。

```text
我第一次用网页AI做项目。请只回答“收到，我们每次只做一小步”，不要开始写代码。
```

**你应该看到什么：**输入的话出现在聊天区，随后出现 AI 的回复。回答不一定一字不差，只要它收到你的意思即可。若一直在转圈，等回复结束；若显示网络错误，先按网页的重试入口。这一步还没有任何需要保存的项目成果。

本课程用 Qwen3 说明大模型协作方法。当前网页提供哪些模型、是否显示模型名称，以实际页面为准；不要求为了匹配名字而安装本地模型或开通 API。网页没显示型号时，记录“网页未显示型号”即可。

## 准备三：先练一次复制、发送和保存

下面用一张只有四行的小纸条练手。成功后再开始正式项目，免得到了长文档时不会保存。

### 1. 复制一段提示词

在下面绿色框右上角点“复制提示词”。按钮显示“已复制”后，切到 AI 网页，点击输入框，Windows 按 `Ctrl + V`，macOS 按 `Command + V`。看一眼开头是“请只输出下面四行”，再点发送。

```text
请只输出下面四行普通文字，不加解释，不加代码框：
# 我的第一次项目记录
项目名称：智慧校园教学平台
本次目标：学会把AI回答保存成文件
完成状态：等待我自己下载并检查
```

“复制”按钮如果不可用，用鼠标从这段提示的第一个字拖到最后一个字，Windows 按 `Ctrl + C`，macOS 按 `Command + C`，再去粘贴。只复制框里的文字，不用复制“复制提示词”这个按钮文字。

### 2. 复制 AI 给你的回答

等 AI 回复结束，使用**这条回答**旁的复制按钮；没有复制按钮时，用鼠标选中四行回答后按复制快捷键。不要复制左侧聊天列表、你的提问和整张网页。

![教学对话示意：学生发送四行文件要求，AI返回四行文字，学生把回答放进本页保存工具](figures/03-对话到文件.svg)

图 00-3：这是教学对话示意，不是千问截图。看清楚：发送的是“要求”，保存的是“回答”。

### 3. 在本教程里下载回答

1. 切回本教程，点击页面右上角的 **“保存 AI 回答”**。
2. 在“文件名”下拉框里选 `00-保存练习.md`。
3. 点击大文字框，按粘贴快捷键，把刚复制的四行回答放进去。
4. 检查第一行是不是 `# 我的第一次项目记录`。如不对，点文字框，按全选快捷键（Windows `Ctrl + A`；macOS `Command + A`），再粘贴正确内容。
5. 点 **“下载这个 .md 文件”**。页面显示“已发起下载”，说明浏览器开始处理下载；还不表示文件已经放到你的项目文件夹。
6. 若浏览器弹出“另存为”窗口，选择“桌面→campus-ai-lab→docs”，再点保存。若没有弹窗，去下一步找“下载”文件夹。

本工具只在当前浏览器里处理你粘贴的文字，不向服务器提交；它不会自动读取你的电脑文件。文字框中的内容**未下载前不要刷新或关闭页面**。

![本教程保存AI回答工具的实际界面，已选择00保存练习并粘贴四行文字，下方可下载复制或打开已有文件](figures/09-保存工具实图.png)

图 00-4：这是本教程保存工具的实际界面。对照文件名、大文字框和下面三个按钮操作。

### 4. 把下载文件放到项目文件夹

**Windows：**按 `Windows 键 + E` 打开文件资源管理器，左侧点“下载”。找到 `00-保存练习.md`，单击选中，按 `Ctrl + X`。再打开“桌面→campus-ai-lab→docs”，按 `Ctrl + V`。

**macOS：**打开访达，左侧点“下载”。选中 `00-保存练习.md`，按 `Command + C`。打开“桌面→campus-ai-lab→docs”，按 `Option + Command + V`，把文件移到这里。

如果浏览器已经直接保存到 `docs`，不再移动。若重复下载得到名字带 `(1)` 的文件，先打开检查，保留内容正确的一份，再改为教程指定名字；已有旧版本可先改名为 `00-保存练习-旧稿.md`，不要不看内容就覆盖。

### 5. 重新打开，证明你真的保存了

不用双击文件，也不用知道用什么软件打开 `.md`：

1. 在教程的“保存 AI 回答”窗口内，点 **“打开已有 .md 文件”**。
2. 在文件选择窗口找到“桌面→campus-ai-lab→docs→00-保存练习.md”，点打开。
3. 检查工具的大文字框中仍是刚才四行，中文没有乱码。
4. 点“复制当前全文”，切到 AI 网页粘贴，**这一次先不要发送**。看见粘贴的是四行回答，就完成练习；清空输入框即可。

做到这里，你已经会最重要的动作了：提示词发出去，回答保存下来，再把文件带回来。

上面这条保存流程用于前期文档；进入第04篇以后，按篇内的“选中指定代码→替换→保存→运行→记录实际结果”完成编码。

后文说“把某文件交给 AI”时，意思是：用本页工具打开那个文件→点“复制当前全文”→切到 AI 输入框→粘贴→发送。**只发文件名，AI 看不到里面的内容。**后文说“在原对话继续”，意思是继续刚才同一个聊天，除非该步明确要求新建对话，否则不要自行换到别的聊天。

## 卡住时，直接照这里处理

| 你遇到的情况 | 现在做什么 |
| --- | --- |
| AI 一口气给出很多代码 | 发送下方第一个纠偏提示。我们还没到编码。 |
| AI 说已经替你建好文件 | 用保存工具自己下载，再重新打开。聊天里的承诺不能代替电脑上的文件。 |
| AI 的回答和示例文字不一样 | 核对本步要求的内容是否齐全，不要求逐字相同。偏离范围时用本步的纠偏提示。 |
| 回复中断了 | 发送下方第二个提示。要拿到完整文档再保存。 |
| 回答有三条反引号包住正文 | 只复制代码框里面的正文；或让 AI 按下方第三个提示重发。 |
| 不知道文件在哪里 | 先看浏览器“下载”记录，再去系统“下载”文件夹；按上面的移动步骤放到 `docs`。 |
| 聊天太长，AI 忘了前面的决定 | 新建对话，把本步注明的输入文件逐份打开、全文复制发送，再发该步提示词。 |
| 不认识某个词 | 发送下方第四个提示，让 AI 先解释，再继续当前一步。 |

```text
我们还在项目构思、分析和设计阶段。请停止生成代码，不要让我安装软件。只按刚才这一步要求，给出对应Markdown文档的完整正文。保留已确认范围，不增加功能。
```

```text
你的上一条回答没有完成。请重新给出这一份文档的完整版本，从标题到最后一段，不要只发后半部分，不要省略为“同上”。如果确实超过单次长度，请先告诉我并等我确认拆分，不要悄悄截断。
```

```text
请把刚才确认的文档完整重发。不要在最外层加三个反引号，不要加“下面是文档”等说明，不要省略任何已确认段落。我会自己复制并下载成.md文件。
```

```text
请先用初中生能听懂的话解释你刚才使用的技术词，每个词配一个我们智慧校园例子。解释完告诉我：当前这一步，我具体只需要做哪一个动作。不要开始下一步。
```

## 给教师：怎样判断这篇带做是否真的有效

请让第一次使用材料的人独立完成“保存练习”和第一份项目想法。观察他能否找到输入框、复制正确内容、找回文件，以及说出自己为什么删掉某个功能。不会时把卡住的位置记下来，修改那一步。浏览器按钮检查与样例完整性检查不能代替这次试教。

00作为入门练习，01—12对应原48学时课程的完整跟做主线，不因11份前期文件再增加11次课。理论、图示和术语可回到[阅读参考版](../reading/index.html)查阅；操作顺序以本手把手教程为准。首次依赖安装和第05篇起的组数据库由教师课前组织准备，真实学生独立跟做与课堂用时仍需试教确认。真实AIRIOT为选做。
