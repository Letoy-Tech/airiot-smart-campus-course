上一章的位置关系继续保留。本章仍在桌面 `campus-ai-lab/app`：修好筛选，再亲手改变页面外观。**不是下载另一份完成版覆盖原工程。** 4学时按1＋2＋1安排：步骤1手算，步骤2—5制作，步骤6检查。

## 第2步：把返回空数组的练习入口，改成真正的筛选

回 `frontend/src/domain/course.ts`，查找 `STUDENT_TODO_C06_BEGIN`。标记内暂时忽略参数并返回 `[]`，因此页面看不到匹配设备；这不等于服务器没有设备。

在同一AI会话发送：

```text
请只给STUDENT_TODO_C06_BEGIN与END之间的完整TypeScript替换代码。
保留filterDevices(devices: Device[], filter: DeviceFilter): Device[]签名。
关键词trim后不区分大小写，匹配设备name或id；关键词/spaceId/category为空
表示该项不限制。online为all时不限制；online/offline/unknown分别严格匹配
device.online===true/false/null。四项必须AND组合。使用filter返回新数组，
不能splice原数组，不能请求新接口，不能增加依赖。随后解释一个OR错误反例。
```

与真实参考实现相同的可用代码是：

```typescript
const keyword = filter.keyword.trim().toLocaleLowerCase()
return devices.filter(
  (device) =>
    (!keyword || `${device.name} ${device.id}`.toLocaleLowerCase().includes(keyword)) &&
    (!filter.spaceId || device.spaceId === filter.spaceId) &&
    (!filter.category || device.category === filter.category) &&
    (filter.online === 'all' ||
      (filter.online === 'online' && device.online === true) ||
      (filter.online === 'offline' && device.online === false) ||
      (filter.online === 'unknown' && device.online === null)),
)
```

只选中C06两条标记中间的内容，粘贴替换，保留注释、函数外层大括号及C08/C12。`&&`连接四个大条件；最后一组里的 `||`是允许选择哪一种通信状态。**不能把所有符号统一改成同一种。**保存文件。


## 第4步：按同一条筛选路线，从16走到1，再走到0

在“设备台账”页面按顺序做，每一步读表格标题里的“条匹配记录”，不是上方“设备总数”：

| 操作 | 应看到什么 |
| --- | --- |
| 点“清除全部筛选” | 当前完整16条，设备总数仍16 |
| “空间”选“教学空间01（模拟）” | 4条 |
| “设备类型”再选“环境” | 1条，ID `teaching_env_01` |
| “在线状态”再选“未知” | 0条，显示“暂无匹配设备，请调整筛选。” |
| 点“清除全部筛选” | 恢复16条，不是原数组被删剩0条 |
| 仅“在线状态”选“未知” | 应含 `teaching_energy_01`，不含 `teaching_env_01` |

再清除条件，在“关键词”输入 `teaching_energy_01`，点该行“查看详情”。应展开“设备详情”，通信状态“未知”；地址末尾包含 `#devices?deviceId=teaching_energy_01`。按浏览器刷新，仍是这个设备。编号用来定位，不能用“数组第几项”猜详情。

将刚才每步的条件和**实际ID/数量**记到证据文件。把记录交给AI时用：

```text
下面是我的实际筛选记录。请按顺序检查四条件AND、unknown严格null、
清除后原数组仍完整。空间01+环境+未知应0；请指出实际哪一步与预测不同。
数量只能引用我的记录，不能补造。若需修C06，先解释原因，再返回标记内
完整代码。详情必须以deviceId定位，不新增未约定设备详情接口。
```

一个能抓出错误的反例是“空间01+环境+未知”：如果用了OR，在线环境设备也可能因为空间符合而混入。出现这种情况就回第2步，不靠增加页面隐藏条件掩盖函数错误。

## 第5步：做自己的页面外观，但不重写行为

在VS Code打开 `frontend/src/views/DeviceCatalog.vue`。搜索 `<style`：教师起点没有样式块，样式来自共用文件。这次只在文件最后的 `</template>` **后面**增加本页样式，不替换模板、不移动请求逻辑。

先把当前 `DeviceCatalog.vue` 全文贴给同一AI会话，再发送：

```text
请只为刚贴的DeviceCatalog.vue增加一个<style scoped>块，不改script/template。
我想让设备表更容易扫描：台账外框圆角、表头浅绿色、行间距稍大；窄于600px
时标题与刷新按钮上下排。使用已有.ledger、.data-table、.page-heading类。
不要改三态颜色含义、教学模拟标识、单位、设备ID、错误提示及按钮行为，
不要引入图标库或依赖。请给可以放在文件末尾的完整样式块，说明一条设计理由。
```

这是与真实模板类名对应的一种最小回答：

```vue
<style scoped>
.ledger {
  border: 2px solid #0f766e;
  border-radius: 16px;
}
.data-table th {
  background: #f0fdfa;
  color: #134e4a;
}
.data-table td {
  padding-top: 1rem;
  padding-bottom: 1rem;

  }

```

`scoped`表示样式只作用于当前页面。复制整块放在文件末尾，保存，浏览器应自动更新；可按自己的选择改变边框色与间距。若已存在你自己写的 `<style>`，不要盲目追加重复规则：把现有样式贴给AI，要求“保留现有决定，合并为一份完整style块”，再只替换该样式块。

页面右键→“检查”，点开发者工具的手机/平板图标进入响应式预览，宽度输入 `390`。确认页面能读、输入框和按钮能用，宽表在自己的滚动区域移动；然后用Tab键移动到“清除全部筛选”并按Enter试一次。浏览器预览不是手机真机验收。

```text
重新给完整style块，说明应替换哪一块，不能要求整包重生成页面。
```

## 第6步：检查空、失败和旧快照，不让好看的页面撒谎
