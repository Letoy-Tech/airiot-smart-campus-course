# 零基础手把手教程：从构思到交付

学生先打开 [index.html](index.html)，按00—12顺序跟做。解压教学包后双击即可离线阅读；使用国内网页AI、首次下载安装工具和依赖需要相应网络条件。[reading/index.html](../reading/index.html)用于补充概念、图示与术语，实际操作主线以这里为准。

前期共11份需求设计文件，保存于桌面 `campus-ai-lab/docs`。第04篇把包内 `resources/student-project` **只复制一次**为旁边的 `campus-ai-lab/app`，以后所有章节都在这份工程继续。各章首次执行自己的 `prepare` 命令；工具记录已准备章节，重复执行保留当前源码，不用独立章节副本替换长期工程。代码通过VS Code修改指定范围，个人运行证据保存到 `app/evidence/chXX.md`。

教师提供完整框架与安全基础，学生学习的是分析问题、给AI准确上下文、审查建议、实现指定业务小块、运行并解释证据。教程不把预置代码说成学生从空文件独立写出的完整系统，也不把复制示例说成已经验证。

## 学生怎样复现

1. 从00开始练会复制、发送、下载与重新打开；按01—03完成本人的设计文件。保存工具只处理文档下载，不自动读取电脑、不调用模型、不上传文字，也不自动保存尚未下载的草稿。
2. 按[第04篇](04-安装工具与第一次改代码.md)安装冻结版本、复制学生起点、设置每个终端的环境、初始化本机账号，完成首次贯通。现有 `app` 不再复制或覆盖。
3. 第05篇起由教师交接每组独立数据库和迁移，使用 `teacher-db`；前期 `first-chain` 仅用于两设备贯通。各篇顺序是读真实文件、预测、给AI上下文、替换指定块、保存、运行、记录；准备后的预期失败不能靠删测试消除。
4. 按[第11篇](11-调试测试与证据.md)区分本人测试、教师数据库执行报告与历史样例；按[第12篇](12-构建交付与接力.md)生成不含秘密的交付目录，在新目录复现，再更新实际交接记录。交付复制用于复现，课堂开发始终保留原 `app`。

课程仍为48学时，适合学过一门语言但缺少项目经验的学生；可用Windows/macOS。必修采用4空间、16设备、28点的固定模拟数据；真实AIRIOT只读接入选做，UI可自主设计，网页AI无需模型API Key。真实控制和外部通知不在必修范围。

## 维护与AI接力

正文源是本目录00—12的Markdown；HTML是生成结果，不单独改正文。维护者先修改对应篇章，再从课程根目录运行：

```sh
node tools/build-walkthrough.mjs
node tools/verify-walkthrough.mjs
```

前期图源确有修改时，先运行 `python3 tools/build-walkthrough-figures.py`；其他图示按各自源文件维护，不为正文小改重复生成全部图。浏览器验证使用 `tools/runtime.mjs` 的本地依赖；需要指定浏览器时采用 `COURSE_CHROMIUM_PATH`，不把作者缓存目录作为学生必需路径。

接力者先读对应篇章、实际源码与最新报告，保留用户修改。R01目录、R02本地空间绑定、R03本地演练、R04点值应从需求追到设计和实际操作；修改接口先同步合同，不让AI另造路径。账号、连接密码、Cookie及CSRF不得进入网页聊天或证据包。

## 已有证据与仍需确认的范围

- [同一工程检查记录](qa/continuous-project.json)：记录逐章准备、重复准备、已编辑块保护、部分TODO预期失败与修复、普通check/build及源码导出检查。按报告里的具体检查项理解PASS，不由此推出真实学生或数据库操作均已验证。
- [阅读页与保存工具记录](qa/verification.json)：记录对应生成版本的复制、下载、文件重开、链接及桌面/窄屏浏览器检查。报告时间和范围对应那一次构建，后续正文变更需要重新生成和验证，不能沿用旧PASS覆盖新版本。

教学AI回答为作者编写，未实际登录千问执行这些提示。真实学生独立跟做、Windows物理电脑、学校网络与数据库交接、完整课堂耗时仍需组织试教；浏览器窄屏模拟不能代替真机。作者工程检查、页面检查和课堂可跟做性是不同证据。

本目录提供当前完整手把手主线。历史ZIP、旧单文件阅读版和旧报告不随Markdown自动更新；交付时应核对包内是否含本目录00—12与 `resources/student-project`，再按该包实际版本阅读。
