# 第04章教师参考：学生两任务的完整判定

本章4学时，建议45＋90＋45分钟；两人一组中途换手。完整答案仅供教师阶段讲评，学生先交预测。章内10分用于形成性诊断，期末映射课程统一评分，不重复加总。

## 课堂完成路径与参考答案

使用`student-chapters/ch04`，教师参考不下发作为个人完成代码。任务A在`frontend/src/api/campus.ts`，参考逻辑为先检查`response.code !== 0`，抛`new ApiError('设备读取未成功，请核对业务响应。', 200, response.code)`；成功返回`{items:response.data.items, observedAt:response.data.observedAt}`。保留code有助于业务失败断言，不以空数组吞掉错误。

任务B在`frontend/src/views/FirstDeviceRead.vue`的onlineLabel：严格true返回在线，false返回离线，null返回未知，其余抛ApiError。加载、快照保留与会话竞态由教师框架提供，学生说明并实际验证，不声称这部分从零实现。

参考流程：当前学生根目录doctor→安装前端依赖→init→build→两个终端启动；未填任务时相关测试失败和TODO提示属于预期。填完再check。访问`http://127.0.0.1:5178/#first-read`，页面first-chain只出现true/null；函数false测试与完整页面false证据分别记。

失败实验保持页面与会话，Chromium request blocking只屏蔽设备GET，点击重新读取。应显示错误、保留两条记录和旧观察时间；取消屏蔽恢复。不得编辑请求路径、刷新页面或改系统时间替代该实验。

## 常见故障与追问

启动教师目录而非学生目录；JAVA_HOME仅设一个终端；PowerShell npm.ps1受限；按旧示例移除/api；未填TODO先要求测试全绿。按启动单核对目录和实际命令，Windows用npm.cmd，不关闭CSRF。

## 课堂替代与时间停点

环境阻塞时使用离线O03和三态独立函数，保留真实错误；教师机器可示范，但学生页面运行记录仍标未执行。 模块二结束先保存当前差异；最后1学时只核验任务卡证据与交接，不加新功能。

## 课后题参考答案

**练习一。** `git diff` 为空，是否一定可以直接提交？  

答案要点：不能。还需检查状态、暂存差异和未跟踪文件；普通 diff 不显示已经暂存的变化，也不证明内容正确。

**练习二。** `/api/campus/devices` 返回 200 和 HTML，最先检查哪里？  

答案要点：核对代理前缀、重写和目标地址，以及请求是否落入前端页面回退；这不是设备 JSON，不能显示加载成功。

**练习三。** 请求屏蔽实验后仍显示旧的两台设备，是否一定失败？  

答案要点：不一定。若明确保留旧快照、旧时间并提示刷新失败，符合可靠性目标；若伪称本次成功，则错误。

**练习四。** 最小桩已经返回两台设备，可否报告完整平台或 AIRIOT 接入完成？  

答案要点：只能报告本次真实覆盖的最小链路。完整规模、空间持久化、授权拒绝、事件和真实接入均需各自证据。
