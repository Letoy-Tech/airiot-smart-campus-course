# 智慧校园教学工程 · 第一条贯通

本工程是48学时课程的独立配套资源，面向学生自带Windows/macOS电脑、教师提供数据库的条件。当前交付范围是**教师参考实现：本地登录 → 能力读取 → 两设备展示**，以及供第04章使用的学生任务入口。第05—12章的写业务、监测、事件和数据库实验仍需逐步制作；不要把本工程当作完整平台。

数据来源固定为`TEACHING_MOCK`；所有设备均为模拟。没有大模型API调用，学生使用通义等网页工具辅助阅读、修改与测试。没有真实AIRIOT访问、远程控制或外部通知。

## 从哪里开始

1. [跨平台启动说明](docs/01-跨平台启动.md)：安装检查、生成本地账号、启动与停止。
2. [第04章首次贯通操作单](docs/04-首次贯通操作单.md)：预测输入、填写两处任务、观察请求与错误。
3. [教师数据库交接单](docs/02-教师数据库交接单.md)：第05章前由教师准备隔离数据库，当前不要求学生自行装MySQL。
4. [资源与章节映射](docs/03-资源与章节映射.md)：哪些文件已经存在，哪些功能仍待制作。
5. [固定夹具说明](fixtures/README.md)：4空间、16设备、28采集点以及独立异常样本。
6. [离线AI练习](../offline-ai/学生练习.md)：网页不可用时替代原章节练习。

## 工程布局

| 目录 | 用途 |
| --- | --- |
| frontend/ | Vue/TypeScript/Pinia页面、统一请求、教师参考实现与测试 |
| backend/ | Java17/Spring Boot3.4.2、会话认证、CSRF、校园只读入口 |
| fixtures/ | 冻结教学数据和测试场景，不含真实学校记录 |
| tools/ | 跨平台入口、夹具检查与学生版生成 |
| docs/ | 操作单、数据库交接与章节任务 |
| evidence/ | 本资源的检查记录，不使用原系统历史结果 |
| .private/ | 在本机初始化时生成的临时教学密码；不分发、不提交 |

本项目无需Redis。认证会话在单个后端进程内存中保存；后端重启后需要重新登录。它用于本机学习，不包含生产部署方案。数据库profile不由默认启动脚本开启。

## 两种拷贝

此目录为教师参考代码，先用它核对环境。教师通过`node tools/make-student.mjs`生成独立`student-workspace/`，其中第04章的两个任务块留给学生填写，参考目录保留原状。生成器拒绝覆盖已有学生目录；学生以后在自己的目录提交Git并继续扩展。

“学生版能编译”和“任务验收完成”是两回事：未填写任务A时应看到清楚的待完成提示，不能悄悄显示伪造成功。整个项目的实验状态见[本轮检查记录](evidence/verification.json)。
