## 关键答案与讲评顺序

C07在 `QualityPolicy.classify`。固定时钟来自catalog的observedAt，不能使用学生电脑当前时间；业务事件时间另由服务端时钟产生。

参考顺序：非null值/时间的非法类型或非法时间 → invalid；任一缺失 → missing；未来超过5000ms → invalid；年龄超过60000ms → stale；否则fresh。采用已有 `missing/value/time` 辅助函数，不能把字符串数值转成合法采样。

```java
if ((!missing(value) && !value(value)) || (!missing(time) && !time(time))) return "invalid";
if (missing(value) || missing(time)) return "missing";
long age = observedAt - time.longValue();
if (age < -5_000) return "invalid";
return age > 60_000 ? "stale" : "fresh";
```

有效0保留；null显示未知且曲线断点。O−60000 fresh、O−60001 stale；O+5000 fresh、O+5001 invalid。历史from/to为闭区间，跨度至多6小时，升序、先筛选后最多1000条；保留null，非法记录带issues，禁止补造时间。图表和表格使用相同time/value对。刷新在上次完成后15秒再安排；离页取消且旧响应不得写回。

## 课后题参考答案


**练习一：**O 为观察时间，合法采样为 O−60000 毫秒和 O−60001 毫秒，分别是什么质量？

答案要点：前者 fresh，后者 stale；共享合同说“超过 60 秒”，边界必须单独测试。

**练习二：**查询成功返回空样本，能否说该设备一直为零？

答案要点：不能。空样本只说明本次范围内没有返回测量；既不能推断零，也不能推断设备坏了。需同时查看窗口、来源及 issues。

**练习三：**上次读取显示 fresh，本次请求失败，前端应把质量改成 stale 吗？

答案要点：不自行重算后端质量。保留上次判断的上下文，明确当前更新失败、快照时间和采样时间，让使用者知道它不是新的质量确认。

**练习四：**只有 1.2 kW 的读数，能否算出本月费用？

答案要点：不能。缺少可核对的累计电量、时间覆盖和计费规则，数值单位也不同。
